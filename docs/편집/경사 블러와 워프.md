# 경사 블러와 워프

**필터 > 블러 / 왜곡**의 **경사 블러**와 **워프**는 내장 노이즈를 이용해 현재 래스터 레이어의 픽셀을 변형합니다.

Substance 3D Painter와 비슷한 조절 흐름을 목표로 한 독자 구현입니다. Adobe의 코드·에셋·런타임을 사용하지 않으며, 같은 수치를 넣었을 때 동일한 결과가 나온다는 의미는 아닙니다.

## 현재 제공하는 변형 소스

두 필터는 **내장 기본 노이즈만** 사용합니다.

- 외부 이미지 불러오기 또는 다른 이미지를 변형 소스로 선택하는 옵션은 없습니다.
- Perlin / Voronoi 종류를 선택하는 옵션은 없습니다.
- 현재 레이어의 밝기를 변형 소스로 선택하는 옵션도 없습니다.
- 대신 소스 블러, 중심값/균형, 대비, 타일링, 시드로 기본 패턴을 조절합니다.

여기서 “소스”는 **변형 방향이나 양을 만드는 노이즈**입니다. 색이 바뀌는 대상 이미지는 현재 레이어입니다. [펄린 노이즈 생성](노이즈.md)은 별도의 기능이므로, 그 메뉴를 먼저 실행해야 경사 블러가 동작하는 것은 아닙니다.

## 공통 옵션

| 옵션 | 범위 | 경사 블러 기본값 | 워프 기본값 |
| --- | --- | --- | --- |
| 강도 | 0.000~1.000 | 0.100 | 0.100 |
| 강도 나눗값 | 1, 10, 100, 1000 | 1 | 10 |
| 소스 블러 | 경사 블러 0.00~20.00 / 워프 0.00~1.00 | 0 | 0 |
| 소스 중심값 / 소스 균형 | 0.00~1.00 | 0.50 | 0.50 |
| 소스 대비 | 0.00~1.00 | 0 | 0 |
| 소스 타일링 | 0.01~16.00 | 1.00 | 1.00 |
| 시드 | 0~99999 | 0 | 0 |

### 강도와 강도 나눗값

강도 0은 원본입니다. 나눗값이 커질수록 같은 강도에서도 효과가 약해져 미세 조절하기 쉽습니다.

강도는 고정 픽셀 이동량이 아닙니다. 이미지 크기와 내부 노이즈 기울기 등을 반영하는 상대값입니다. 경사 블러와 워프의 기본 나눗값도 다르므로 강도 숫자 하나만 보고 효과를 직접 비교하지 마세요.

### 소스 블러

노이즈를 부드럽게 만들어 거친 변형을 완화합니다. **레이어 결과를 단순한 가우시안 블러로 흐리는 옵션이 아닙니다.** 경사 블러와 워프의 표시 범위가 다르므로 같은 숫자가 같은 소스 처리량을 뜻하지 않습니다.

### 소스 중심값 / 균형과 대비

노이즈의 값 분포와 대비를 바꿉니다. 중심값/균형을 이동하거나 대비를 높이면 노이즈의 일부가 낮거나 높은 값으로 몰려 변형 성격이 달라집니다. 강하게 제한된 영역에서는 기울기가 줄어 효과가 균일하지 않을 수 있습니다.

### 소스 타일링과 시드

타일링은 노이즈의 반복 밀도, 시드는 패턴을 바꿉니다. 이것은 최종 텍스처의 가장자리 이음새를 자동 보정하거나 앱의 텍스처 타일링 기능을 켜는 옵션이 아닙니다.

## 경사 블러

노이즈의 기울기를 따라 여러 위치를 샘플링하고 결과를 합칩니다.

| 방식 | 동작과 활용 |
| --- | --- |
| 블러 | 이동 경로에서 얻은 픽셀을 평균해 흐르는 듯한 번짐을 만듭니다. |
| 최소 | 샘플의 작은 채널 값을 선택합니다. 흑백 이미지에서는 어두운 쪽이 퍼지는 효과를 만들 수 있습니다. |
| 최대 | 샘플의 큰 채널 값을 선택합니다. 흑백 이미지에서는 밝은 쪽이 퍼지는 효과를 만들 수 있습니다. |

최소·최대는 “가장 어두운/밝은 픽셀 하나를 통째로 선택”하는 방식이 아니라 채널별 연산입니다. 색상 이미지나 반투명 가장자리에서는 단순한 흑백 팽창·침식과 결과가 다를 수 있습니다.

**품질**은 0.00~1.00, 기본값 1.00입니다. 내부 경로 샘플링 단계 수를 조절하며 낮을수록 가볍고 높을수록 촘촘하게 계산합니다. 강도를 바꾸는 옵션과는 다릅니다.

### 조절 순서

1. 원본을 복제하고 블러 방식으로 시작합니다.
2. 강도를 낮게 두고 소스 타일링·시드로 큰 패턴을 고릅니다.
3. 소스 블러로 작은 요철을 정리합니다.
4. 필요하면 최소·최대로 바꿔 명암의 확장 방향을 비교합니다.
5. 품질을 낮춰 빠르게 비교한 뒤 최종 적용 전 다시 확인합니다.
6. 확인 후 원본 해상도의 결과를 점검합니다.

## 워프

현재 메뉴 이름은 **워프**입니다. “워프 블러”라는 별도 메뉴나 번짐 비율 옵션은 없으며, 소스 처리와 워프 방식을 조절합니다.

| 방식 | 동작 | 활성 옵션 |
| --- | --- | --- |
| 일반 워프 | 노이즈 기울기를 따라 픽셀 위치를 변형합니다. | 방향 각도·다방향 혼합은 사용하지 않음 |
| 방향 워프 | 지정 각도와 노이즈 값에 따라 한 방향으로 변형합니다. | 방향 워프 각도 |
| 다방향 워프 | 지정 각도를 기준으로 90도씩 다른 네 방향을 사용합니다. | 방향 각도·다방향 혼합 |

방향 워프 각도는 0~360도이며 기본값은 0도입니다. 일반 워프에서는 각도 입력이 비활성화됩니다.

### 다방향 혼합 방식

| 혼합 | 설명 |
| --- | --- |
| 평균 | 네 방향의 샘플을 평균합니다. |
| 최대 | 네 방향 샘플의 채널별 큰 값을 사용합니다. |
| 최소 | 네 방향 샘플의 채널별 작은 값을 사용합니다. |
| 연쇄 | 앞 방향에서 이동한 위치를 다음 방향의 출발점으로 사용합니다. 독립된 네 결과의 평균과 다릅니다. |

### 조절 순서

1. 일반 워프로 변형 크기를 확인합니다.
2. 움직임이 너무 크면 강도를 낮추거나 나눗값을 높입니다.
3. 한 방향으로 늘이려면 방향 워프와 각도를 사용합니다.
4. 여러 방향의 질감을 섞으려면 다방향 워프로 전환합니다.
5. 평균과 연쇄를 비교하고, 흑백 기반 재료에서는 최소·최대도 시험합니다.

## 투명도·경계·선택

- RGB만 따로 움직이는 것이 아니라 알파를 포함한 이미지 샘플을 처리하므로 반투명 가장자리도 바뀔 수 있습니다.
- 이미지 경계 밖의 샘플은 가장자리로 제한됩니다. 반대편 가장자리로 이어지는 래핑 샘플링이 아닙니다.
- 픽셀 선택은 최종 결과를 적용할 위치를 제한하지만, 변형 계산에서 주변 원본 픽셀을 참조하는 것까지 차단하지는 않습니다.
- 마스크 편집 중에는 현재 필터 메뉴를 실행할 수 없습니다.

## 미리보기와 최종 결과

조작 중에는 긴 변이 1024px를 넘는 이미지를 축소해 계산하고 표시 크기로 다시 확대합니다. 확인을 누르면 원본 해상도로 다시 계산합니다.

따라서 조작 중 미리보기에서 잘 보이지 않던 작은 요철이 최종 결과에 나타날 수 있습니다. 계산은 백그라운드에서 수행되며, 오래된 요청은 취소하고 최신 설정으로 교체합니다. 노이즈 소스 설정이 같으면 계산한 변형 필드를 재사용하지만, 원본 해상도 최종 계산에는 추가 시간이 필요합니다.

이 설명은 **필터 대화상자**의 비동기 처리에 관한 것입니다. [AO 베이크](../도구/베이크.md)의 GPU 처리·취소 반응과 동일한 구조가 아닙니다.
