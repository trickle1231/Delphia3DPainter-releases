# 필터

필터는 활성 래스터 레이어에 적용됩니다. 선택 영역이 있으면 그 영역에만 적용됩니다. 그룹 레이어와 잠긴 레이어에는 적용할 수 없습니다.

**필터** 메뉴에서 색상 반전, HSV 조정 (`Ctrl+U`), 톤 커브 (`Ctrl+M`), 컬러 밸런스, 레벨 (`Ctrl+L`)을 사용할 수 있습니다.

| 필터 | 사용 예 |
| --- | --- |
| 색상 반전 | 명암 또는 색의 방향을 반대로 바꿉니다. |
| HSV 조정 | 색상·채도·명도를 한 번에 조절합니다. |
| 톤 커브, 레벨 | 밝은 영역과 어두운 영역의 대비를 정리합니다. |
| 컬러 밸런스 | 그림자·중간톤·밝은 영역의 색감 균형을 조절합니다. |

HSV, 톤 커브, 컬러 밸런스, 레벨은 미리보기를 제공하는 조정 대화상자에서 결과를 확인한 뒤 적용하거나 취소할 수 있습니다. 필터는 레이어 픽셀을 바꾸므로, 적용 전 프로젝트를 저장하거나 레이어를 복제해 두는 편이 좋습니다. 레이어 마스크를 편집 중이면 색상 이미지 대신 마스크의 흑백 값에 필터가 적용됩니다. 체험판에서는 일부 고급 필터가 제한될 수 있습니다.
