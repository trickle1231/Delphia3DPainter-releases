# 필터 사용법과 색상 조정

색상 조정은 **필터 > 색상 조정**에서 실행합니다. 레이어의 오른쪽 클릭 메뉴에서도 필터를 찾을 수 있습니다. 전체 목록은 [필터 메뉴](../필터.md)를 참고하세요.

## 기본 작업 순서

1. 작업할 재질·텍스처 캔버스를 선택합니다.
2. 표시되고 잠겨 있지 않은 래스터 레이어를 한 개 선택합니다.
3. 일부만 바꾸려면 먼저 2D 픽셀 선택 영역을 만듭니다.
4. 필터를 열어 값을 조정하고 2D·3D 표시를 확인합니다.
5. **확인 / OK**로 확정하거나 **취소 / Cancel**로 원래 상태로 돌아갑니다.
6. 결과가 만족스러우면 프로젝트를 저장합니다.

색 반전은 별도의 조정 대화상자 없이 즉시 적용됩니다. 그 외 이 문서에서 설명하는 필터는 대화상자 미리보기를 사용합니다.

## 적용 범위와 선택

| 상태 | 동작 |
| --- | --- |
| 픽셀 선택 없음 | 대상 레이어의 전체 이미지에 적용합니다. |
| 2D 픽셀 선택 있음 | 선택 마스크를 기준으로 원본과 필터 결과를 합성합니다. 선택 밖은 원본을 유지합니다. |
| 부분 강도의 선택 경계 | 선택 마스크의 강도에 비례해 원본과 결과를 혼합합니다. |
| 마스크 편집 중 | 현재 메뉴에서는 실행할 수 없습니다. 마스크 편집을 종료해야 합니다. |
| 여러 레이어 선택 | 상단 필터 메뉴를 사용할 수 없습니다. 대상 한 개만 선택하세요. |
| 그룹·비래스터·잠금·숨김 상태 | 편집 가능한 래스터 레이어로 바꾸고 상위 그룹 상태도 확인하세요. |

3D 면 선택과 2D 픽셀 선택은 서로 다른 정보입니다. 필터의 최종 합성에 전달되는 것은 캔버스의 **픽셀 선택 마스크**이므로, 3D 면을 선택했다는 이유만으로 모든 필터가 그 면 안에서만 실행된다고 가정하지 마세요.

선택은 **결과가 적용되는 위치**를 제한합니다. 경사 블러·워프처럼 주변 픽셀을 참조하는 필터는 선택 밖 픽셀도 계산에 사용할 수 있습니다. 선택 경계를 샘플링 차단벽처럼 취급하지는 않습니다.

## 미리보기와 성능

- 대화상자의 이미지 계산은 백그라운드 작업으로 실행됩니다.
- 슬라이더 변경은 약 30ms 단위로 모아 처리합니다. 빠르게 여러 번 바꾸면 오래된 계산을 취소하고 최신 설정을 반영합니다.
- 미리보기는 대화상자를 열 때의 원본에서 다시 계산합니다. 슬라이더를 왕복한다고 효과가 계속 누적되지는 않습니다.
- 레벨의 히스토그램도 별도 백그라운드 작업으로 계산됩니다.
- **확인**을 누르면 설정을 고정하고 최신 결과를 계산한 뒤 확정합니다. 처리 중에는 확인 버튼이 비활성화되지만 취소는 사용할 수 있습니다.
- 취소하거나 창을 닫으면 미리보기를 원복하고 진행 중인 작업의 취소를 요청합니다.

백그라운드 계산이 모든 상황에서 즉시 반응하거나 메모리를 적게 쓴다는 뜻은 아닙니다. 고해상도 이미지, 높은 노이즈 세부도, 경사 블러의 높은 품질은 계산량을 늘립니다.

**경사 블러·워프만** 큰 이미지의 조작 중 미리보기를 긴 변 최대 1024px로 줄여 계산합니다. 확인 시에는 원본 해상도로 다시 계산하므로 미세한 디테일이 미리보기와 달라질 수 있습니다. 모든 색상 필터와 노이즈가 축소 미리보기를 사용한다고 이해하지 마세요.

## 색 반전

RGB 값을 반전하고 원래 알파를 유지합니다. 선택 영역이 있으면 해당 강도에 따라 반전 결과를 섞습니다. 흑백 이미지의 명암 반전이나 보색 계열의 재배색에 사용합니다.

별도 대화상자가 없으므로 원본이 필요하면 먼저 레이어를 복제하세요. 반전 뒤 색이 예상과 다르면 레이어 혼합 모드와 불투명도도 확인하세요.

## HSV 조정

기본 단축키는 `Ctrl+U`입니다.

| 항목 | 범위 | 의미 |
| --- | --- | --- |
| 색조 | -180~180 | 색상환에서 색의 위치를 이동합니다. |
| 채도 | -100~100 | 색의 선명함을 줄이거나 늘립니다. |
| 명도 | -100~100 | HSV의 명도 값을 조정합니다. |

같은 음영 구조를 유지하면서 색상 계열을 바꾸는 작업에 적합합니다. 원래 채도가 거의 없는 부분은 색조만 바꿔도 변화가 작을 수 있습니다.

## 톤 커브

기본 단축키는 `Ctrl+M`입니다. 가로축은 입력 밝기, 세로축은 출력 밝기입니다.

- **RGB**는 전체 밝기 곡선이며, **빨강·초록·파랑**은 각 채널 곡선입니다.
- 곡선 위의 제어점을 드래그해 조절합니다.
- 빈 위치를 클릭하면 제어점을 추가할 수 있습니다. 끝점을 포함해 최대 8개입니다.
- 중간 제어점은 오른쪽 클릭으로 제거할 수 있습니다.
- **커브 초기화**로 선택 채널의 곡선을 기본 상태로 되돌립니다.
- 채널을 바꿔도 다른 채널에 지정한 곡선을 보관합니다.

완만한 S자 곡선은 대비 조절에, 특정 채널의 곡선은 색 편향 조절에 사용할 수 있습니다. 브러시 설정의 **필압 커브**와는 별개의 기능이며 제어점 조작 규칙도 다릅니다.

## 컬러 밸런스

**그림자·중간톤·하이라이트**를 선택한 뒤 각 범위의 색 균형을 조절합니다.

| 축 | 음수 방향 | 양수 방향 |
| --- | --- | --- |
| 청록 / 빨강 | 청록 | 빨강 |
| 자홍 / 초록 | 자홍 | 초록 |
| 노랑 / 파랑 | 노랑 | 파랑 |

각 축은 -100~100입니다. 톤 범위를 바꾸어도 앞서 지정한 다른 범위의 값은 유지되므로 그림자는 차갑게, 하이라이트는 따뜻하게 만드는 식으로 함께 조정할 수 있습니다.

**명도 유지**는 색 균형을 바꾸면서 밝기 변화를 줄이는 옵션입니다. 강한 보정에서는 채널이 포화될 수 있으므로 최종 색을 확인하세요.

## 레벨

기본 단축키는 `Ctrl+L`입니다.

- **채널**: RGB 또는 빨강·초록·파랑 중에서 선택합니다.
- **입력 레벨**: 검정점, 중간톤, 흰점을 조정합니다. 히스토그램을 보며 사용할 명암 범위를 정합니다.
- **출력 레벨**: 최종 검정·흰색의 범위를 줄이거나 바꿉니다.

입력 검정점과 흰점을 과도하게 좁히면 어두운 부분이나 밝은 부분의 디테일이 사라질 수 있습니다. 채널 변경 후에는 현재 채널과 입력·출력 핸들 값을 다시 확인하세요.

## 그라디언트 맵

원본 픽셀의 밝기를 기준으로 **어두운색 → 중간색 → 밝은색**을 대응시킵니다. 캔버스 위에서 방향을 드래그하는 그라디언트 도구와 다릅니다.

| 항목 | 범위·선택 | 의미 |
| --- | --- | --- |
| 프리셋 | 흑백, 따뜻한 흙색, 차가운 돌색, 사용자 지정 | 세 색의 기본 조합을 선택합니다. |
| 어두운색·중간색·밝은색 | 색 선택 | 버튼을 눌러 원하는 색으로 바꿉니다. 색을 직접 바꾸면 사용자 지정으로 전환됩니다. |
| 중간색 위치 | 1~99%, 기본 50% | 중간색이 대응하는 밝기 위치입니다. |
| 적용 강도 | 0~100%, 기본 100% | 원본과 재배색 결과를 섞습니다. 0%는 원본입니다. |
| 그라디언트 반전 | 켜기/끄기 | 밝기와 색상의 대응 방향을 뒤집습니다. |

흑백 노이즈나 AO를 재배색하는 데 사용할 수 있습니다. 알파를 새로 채우는 기능은 아니므로, 투명한 이미지에 색이 보이지 않으면 먼저 노이즈 생성의 투명도 옵션을 확인하세요.

## 노출 / 대비

| 항목 | 범위 | 기본값 |
| --- | --- | --- |
| 노출 | -5.00~5.00 EV | 0 |
| 대비 | -100~100 | 0 |

노출은 전체 밝기를, 대비는 밝고 어두운 부분의 차이를 조절합니다. 일반 텍스처 픽셀에 적용하는 보정 기능이며 RAW 현상이나 HDR 데이터 복원 기능은 아닙니다. 밝은 부분이 이미 흰색으로 포화됐다면 노출을 낮춰도 원래 디테일이 복원되지는 않습니다.

## 색온도 / 틴트

| 항목 | 범위 | 방향 |
| --- | --- | --- |
| 색온도 | -100~100 | 음수는 차갑게, 양수는 따뜻하게 |
| 틴트 | -100~100 | 음수는 초록, 양수는 자홍 |

색온도는 켈빈 단위 입력이 아닌 상대적인 색감 조정입니다. 두 값의 기본값은 0입니다.

## 그림자 / 하이라이트

| 항목 | 범위 | 기본값 |
| --- | --- | --- |
| 그림자 | -100~100 | 0 |
| 하이라이트 | -100~100 | 0 |
| 영향받는 명암 범위 | 10~100% | 50% |

그림자와 하이라이트 모두 **양수는 밝게, 음수는 어둡게** 조절합니다. 예를 들어 어두운 부분을 올리고 밝은 부분을 누르려면 그림자는 양수, 하이라이트는 음수로 설정합니다. 영향 범위를 넓히면 중간톤까지 더 많이 바뀔 수 있습니다.

## 결과가 예상과 다를 때

1. 현재 레이어와 재질·캔버스가 맞는지 확인합니다.
2. 남아 있는 픽셀 선택 영역을 확인하고, 전체에 적용하려면 선택을 해제합니다.
3. 레이어 및 상위 그룹의 표시·잠금·혼합 모드·불투명도를 확인합니다.
4. 색상이 바뀌지 않는 투명 영역은 [노이즈와 투명도](노이즈.md)의 설명을 확인합니다.
5. 2D와 3D 표시가 어긋나면 [표시/타일 새로고침](../레이어.md)을 확인합니다.
6. 필터가 비활성화되면 마스크 편집·다중 선택·Lite 상태인지 확인합니다.

노이즈 생성과 블러·변형은 각각 [노이즈](노이즈.md), [경사 블러와 워프](경사%20블러와%20워프.md)에 상세히 설명되어 있습니다.
