# 일반 노이즈와 펄린 노이즈

**필터 > 노이즈 / 생성**에서 현재 래스터 레이어에 노이즈를 더하거나 채울 수 있습니다. 새 레이어를 자동으로 만드는 기능은 아닙니다. 기존 그림을 보존하려면 먼저 별도 래스터 레이어를 추가하세요.

## 두 필터의 차이

| 필터 | 패턴 | 주된 사용처 |
| --- | --- | --- |
| 일반 노이즈 추가 | 각 픽셀의 무작위 변화 | 미세한 입자, 거친 표면, 균일한 색면의 작은 변화 |
| 펄린 노이즈 | 주변 값과 부드럽게 이어지는 패턴 | 구름 같은 덩어리, 큰 명암 변화, 재배색용 바탕 |

펄린 노이즈는 여러 옥타브를 합성하는 그라디언트 기반 노이즈입니다. 경사 블러·워프 내부에서 변형 소스로 사용하는 기본 노이즈와는 별도의 필터입니다. 일반·펄린 노이즈 메뉴에 Voronoi 선택 기능은 없습니다.

## 공통 옵션

| 옵션 | 범위·기본값 | 설명 |
| --- | --- | --- |
| 방식 | 기존 색에 노이즈 추가 / 노이즈로 채우기 | 원본에 변화를 더할지, 노이즈 패턴을 채움 결과로 사용할지 선택합니다. |
| 강도 | 0~100% | 0%는 원본 그대로입니다. 원본과 효과 결과의 혼합 정도입니다. |
| 시드 | 0~99999, 기본 1337 | 패턴을 결정합니다. 같은 이미지 크기·설정·시드에서는 같은 패턴을 재현할 수 있습니다. |
| 단색 노이즈 | 기본 켜짐 | RGB에 같은 노이즈 값을 사용합니다. 끄면 채널마다 다른 값을 사용해 색 노이즈를 만듭니다. |
| 투명도 유지 | 기본 켜짐 | 원본 알파를 유지합니다. 끄면 강도에 따라 알파를 불투명 쪽으로 증가시킵니다. |

**단색 노이즈**를 켠 채 색상 이미지에 노이즈를 더한다고 원본이 흑백으로 변하는 것은 아닙니다. 각 색 채널에 더하는 변화량이 같다는 의미입니다.

### 기본 설정

- 일반 노이즈: **기존 색에 노이즈 추가**, 강도 **20%**
- 펄린 노이즈: **노이즈로 채우기**, 강도 **100%**
- 두 필터 모두 단색 노이즈와 투명도 유지가 켜져 있습니다.

## 펄린 전용 옵션

| 옵션 | 범위 | 기본값 | 효과 |
| --- | --- | --- | --- |
| 크기 (픽셀) | 2~2048 | 128 | 값이 커질수록 기본 패턴이 크게 이어집니다. |
| 세부도 (옥타브) | 1~8 | 4 | 높은 주파수의 세부 변화를 추가합니다. 높을수록 계산량도 증가합니다. |

크기는 픽셀 기준입니다. 해상도를 바꾸고 같은 크기 값을 쓰면 텍스처 전체에 보이는 패턴 밀도가 달라질 수 있습니다. 별도의 이음새 없는 타일 생성 옵션은 제공하지 않으므로, 반복 텍스처로 사용할 때는 가장자리를 직접 확인하세요.

## 빈 레이어를 노이즈로 채우기

1. 작업할 캔버스에서 **래스터 레이어 추가**를 실행합니다.
2. 새 레이어 하나만 선택합니다.
3. **필터 > 노이즈 / 생성 > 펄린 노이즈** 또는 **일반 노이즈 추가**를 엽니다.
4. 방식을 **노이즈로 채우기**로 선택합니다.
5. **투명도 유지**를 끕니다.
6. 우선 강도 **100%**로 결과가 보이는지 확인합니다.
7. 펄린이라면 크기·세부도·시드를 조절합니다.
8. 확인으로 적용한 뒤 레이어 불투명도와 혼합 모드로 다른 그림과 합성합니다.

빈 레이어는 알파가 0이므로 투명도 유지를 켜면 노이즈가 계산되어도 보이지 않을 수 있습니다. 이는 빈 캔버스가 없는 상태와 다릅니다. 이미지 자체가 없는 대상은 필터를 실행할 수 없습니다.

투명도 유지를 끄더라도 강도가 100%보다 낮으면 완전히 불투명해지지 않을 수 있습니다. 예를 들어 원래 완전 투명한 곳에 강도 50%를 적용하면 알파도 대략 절반 수준으로 채워집니다.

## 기존 그림에 질감만 더하기

1. 원본 레이어를 복제하거나 프로젝트 사본을 저장합니다.
2. **기존 색에 노이즈 추가**와 **투명도 유지**를 선택합니다.
3. 낮은 강도에서 시작해 질감이 필요한 수준까지 올립니다.
4. 형태를 바꾸지 않고 채널별 얼룩만 추가하려면 단색 노이즈의 켜짐/꺼짐을 비교합니다.

**노이즈로 채우기**는 기존 색의 질감을 조금 거칠게 만드는 것과 다릅니다. 강도 100%에서는 선택된 부분의 색을 생성한 노이즈로 대체합니다.

## 응용과 주의사항

- 펄린 노이즈를 만든 뒤 [그라디언트 맵](필터.md)을 사용하면 흙색·돌색 같은 색조의 바탕을 만들 수 있습니다.
- 일부에만 만들려면 일반 이미지 필터와 동일하게 먼저 픽셀 선택 영역을 만듭니다.
- 시드를 비교할 때 다른 설정과 해상도는 고정하는 편이 좋습니다.
- 고해상도에 높은 옥타브를 사용하면 시간이 걸릴 수 있습니다. 이 필터에는 경사 블러·워프의 1024px 축소 미리보기 규칙이 적용되지 않습니다.
- 확인 전 미리보기는 원본 기준이지만, 확인 후 필터를 다시 실행하면 이미 처리된 픽셀에 다시 적용됩니다.
