# 레이어와 마스크

레이어는 텍스처 편집을 분리해 관리하는 기본 단위입니다. **레이어 > 레이어 추가**에서 래스터, 채우기, 소스 텍스처, 이미지 불러오기 레이어를 만들 수 있습니다.

| 레이어 종류 | 용도 |
| --- | --- |
| 래스터 | 브러시·지우개·채우기·필터로 직접 편집하는 일반 레이어입니다. |
| 채우기 | 색이나 채우기 기반의 내용을 레이어로 관리할 때 사용합니다. |
| 소스 텍스처 / 이미지 불러오기 | 등록한 소스 또는 외부 이미지를 현재 캔버스 작업에 가져옵니다. |

이미지와 베이크 결과를 가져오면 래스터 레이어로 추가됩니다. 페인팅이나 필터를 적용하기 전에는 활성 레이어가 편집 가능한 래스터 레이어인지 확인하세요.

레이어는 복사·잘라내기·붙여넣기할 수 있고, `Ctrl+G`로 선택 레이어를 그룹으로 묶을 수 있습니다. `Ctrl+E`는 선택 레이어를 바로 아래 레이어와 병합합니다.

## 표시와 합성

각 레이어에서 표시 여부, 불투명도, 혼합 모드, 잠금을 조절할 수 있습니다. 그룹을 숨기면 하위 레이어도 함께 표시되지 않습니다. 병합은 여러 레이어의 표시 결과를 한 이미지로 만듭니다. 병합된 이미지 하나에서 원래 레이어를 자동 분리하는 기능은 아니므로 원본이 필요하면 먼저 복제하거나 `.dpp` 사본을 저장하세요. 실수한 직후에는 실행 취소 가능 여부를 확인하세요.

## 레이어 마스크

마스크는 레이어의 보이는 부분을 흑백으로 제어합니다. 흰색은 보이게, 검은색은 숨기게 처리합니다. 마스크는 복사·붙여넣기가 가능하며 `Q`로 잠시 확인할 수 있습니다. 현재는 마스크 편집 중 상단 필터와 레이어 오른쪽 클릭 메뉴가 차단됩니다. 일반 필터로 마스크 값을 직접 보정할 수 있다고 가정하지 마세요.

마스크를 만들었다면 레이어 패널에서 현재 선택 대상이 레이어 본문인지 마스크인지 확인하세요. 선택 영역을 먼저 만들면 필요한 부분만 마스크를 편집할 수 있으며, 3D 선택은 모델 면을 기준으로 범위를 제한합니다. 선택 방식의 차이는 [선택과 변형](선택과 변형.md)을 참고하세요.

## 마스크 편집 중의 작업 제한

마스크 편집은 특정 레이어를 대상으로 유지합니다. 편집 도중에는 레이어 추가·재정렬·그룹 생성이나 일반 필터 실행 등 일부 명령이 제한됩니다. 종료 또는 적용 절차를 마친 뒤 레이어 본문 작업으로 돌아가세요.

3D 면 기반 마스크 선택과 일반 2D 픽셀 선택은 동일한 데이터가 아닙니다. 자세한 적용 범위는 [선택과 변형](선택과%20변형.md), [필터 사용법](필터.md)을 참고하세요.

## 병합 명령의 차이

| 명령 | 결과 |
| --- | --- |
| 아래 레이어 병합 | 같은 상위 그룹 안에서 아래쪽의 병합 가능한 레이어와 합칩니다. |
| 그룹 병합 | 그룹 안의 레이어들을 한 래스터 결과로 정리합니다. |
| 보이는 레이어 복사본 병합 | 원본들을 유지하면서 표시 결과의 합성본을 추가합니다. |
| 보이는 레이어 병합 | 표시되는 레이어들을 합쳐 정리합니다. 원본 분리가 필요하면 복사본 병합을 먼저 검토하세요. |

마스크와 불투명도·혼합 모드가 픽셀 결과에 반영될 수 있으므로 병합 전후의 색과 투명도를 확인하세요.

## AO 결과와 마스크

AO Bake V2의 현재 지원 경로는 레이어 패널 추가 메뉴의 **베이크 레이어 추가 > AO (GPU Bake V2)**입니다. [AO 베이크](../도구/베이크.md)를 참고하세요.

오른쪽 클릭 메뉴에 남아 있는 **베이크 마스크 추가 > AO / Cavity**는 새 V2 결과 캐시와 별도인 이전 경로를 사용합니다. V2에서 계산하면 이 메뉴로 곧바로 마스크를 만들 수 있다고 안내하지 않습니다. 결과가 없다는 메시지가 나올 수 있습니다.
