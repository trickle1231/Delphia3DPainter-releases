# 레이어와 마스크

레이어는 텍스처 편집을 분리해 관리하는 기본 단위입니다. `레이어 > 레이어 추가`에서 래스터, 채우기, 소스 텍스처, 이미지 불러오기 레이어를 만들 수 있습니다.

| 레이어 종류 | 용도 |
| --- | --- |
| 래스터 | 브러시·지우개·채우기·필터로 직접 편집하는 일반 레이어입니다. |
| 채우기 | 색이나 채우기 기반의 내용을 레이어로 관리할 때 사용합니다. |
| 소스 텍스처 / 이미지 불러오기 | 등록한 소스 또는 외부 이미지를 현재 캔버스 작업에 가져옵니다. |

이미지와 베이크 결과를 가져오면 래스터 레이어로 추가됩니다. 페인팅이나 필터를 적용하기 전에는 활성 레이어가 편집 가능한 래스터 레이어인지 확인하세요.

레이어는 복사·잘라내기·붙여넣기할 수 있고, `Ctrl+G`로 선택 레이어를 그룹으로 묶을 수 있습니다. `Ctrl+E`는 선택 레이어를 바로 아래 레이어와 병합합니다.

## 표시와 합성

각 레이어에서 표시 여부, 불투명도, 혼합 모드, 잠금을 조절할 수 있습니다. 그룹을 숨기면 하위 레이어도 함께 표시되지 않습니다. 병합은 원본 레이어를 분리된 상태로 되돌릴 수 없으므로, 중요한 작업은 먼저 `.dpp`로 저장하세요.

## 레이어 마스크

마스크는 레이어의 보이는 부분을 흑백으로 제어합니다. 흰색은 보이게, 검은색은 숨기게 처리합니다. 마스크는 복사·붙여넣기가 가능하며 `Q`로 잠시 확인할 수 있습니다. 마스크를 편집 중일 때 필터도 색상 이미지가 아닌 마스크 값에 적용됩니다.

마스크를 만들었다면 레이어 패널에서 현재 선택 대상이 레이어 본문인지 마스크인지 확인하세요. 선택 영역을 먼저 만들면 필요한 부분만 마스크를 편집할 수 있으며, 3D 선택은 모델 면을 기준으로 범위를 제한합니다. 선택 방식의 차이는 [선택과 변형](선택과 변형.md)을 참고하세요.
