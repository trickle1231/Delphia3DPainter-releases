# 선택과 변형

선택 영역을 만들면 브러시, 채우기, 필터 같은 편집을 필요한 범위로 제한할 수 있습니다.

## 2D 선택

**선택 > 2D**에서 자유 선택, 사각 선택, 폴리곤 선택, 자유 변형을 고릅니다. 선택 도구로 만든 영역은 텍스처 픽셀을 기준으로 하며, 브러시·채우기·필터의 적용 범위를 제한합니다.

- `Ctrl+A`: 현재 2D 텍스처 전체 선택
- `Ctrl+I`: 선택 반전
- `Ctrl+D`: 선택 해제
- `Ctrl+T`: 자유 변형. 선택한 픽셀을 이동·변형한 뒤 `Enter`로 확정하거나 `Esc`로 취소합니다.

## 3D 선택

**선택 > 3D**에서 면, 자유 선택, 사각 선택, 메시 선택을 고릅니다. 3D 선택은 모델 표면의 면을 대상으로 하며, 화면에서 그린 범위와 겹치는 면이 선택됩니다. 따라서 2D처럼 그린 윤곽 자체가 픽셀 선택 영역이 되지는 않습니다.

선택한 면만 브러시·채우기·마스크 편집의 대상으로 제한할 수 있습니다. `Ctrl+A`, `Ctrl+I`, `Ctrl+D`는 각각 전체 면 선택, 선택 반전, 선택 해제입니다.

명령은 마우스가 놓인 2D 또는 3D 뷰를 기준으로 동작합니다. 3D에서는 화면에서 그린 범위와 겹치는 모델 면을 선택하는 방식이므로, 필요하면 시점을 바꿔 결과를 확인하세요.

## 필터와 함께 사용할 때

일반 이미지 필터는 캔버스의 픽셀 선택 마스크를 받아 선택 영역 밖을 원본으로 유지합니다. 3D 면 선택은 별도 정보이므로 **3D에서 면 선택 → 모든 필터가 해당 면에만 적용**되는 흐름으로 단정할 수 없습니다.

경사 블러·워프는 선택 범위 안의 결과를 만들면서 범위 밖 원본 픽셀을 샘플링할 수 있습니다. 선택은 결과를 적용할 위치의 제한이며 주변 픽셀을 참조하지 못하게 하는 경계는 아닙니다.

마스크 편집 중에는 일반 필터 메뉴가 차단됩니다. 대상 레이어·선택 상태·모드를 확인한 뒤 [필터 사용법](필터.md)의 순서로 진행하세요.
