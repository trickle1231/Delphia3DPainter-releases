# 델피아 3D 페인터 위키

델피아 3D 페인터는 레이어 기반의 3D 손맵 텍스처 페인팅 도구입니다. 모델의 UV 텍스처를 2D에서 정밀하게 편집하거나, 3D 모델 표면에 직접 칠할 수 있습니다.

## 시작하기

- [프로젝트 시작](시작하기/프로젝트 시작.md): 모델을 불러오고 캔버스를 연결해 첫 작업을 시작합니다.
- [화면과 패널](시작하기/화면과 패널.md): 작업 영역과 주요 패널의 역할을 확인합니다.
- [기본 조작법](시작하기/기본 조작법.md): 자주 쓰는 도구와 보기 조작을 빠르게 익힙니다.
- [2D와 3D 작업](시작하기/2D와 3D 작업.md): 두 작업 영역의 차이와 함께 쓰는 흐름을 알아봅니다.
- [저장 및 내보내기](시작하기/저장 및 내보내기.md): 프로젝트, 이미지, ORA, 모델을 저장하거나 내보냅니다.

## 작업 전 확인

- 불러오기 지원 형식은 OBJ와 FBX입니다. 모델에는 유효한 UV가 필요합니다.
- 재질마다 알베도, 이미션, 메탈릭, 러프니스, AO 텍스처 슬롯을 사용할 수 있습니다. 일반적인 베이스 컬러 작업은 알베도 슬롯을 권장합니다.
- `.dpp`는 모델 경로와 캔버스·레이어·마스크 등의 편집 상태를 보관하는 작업 원본입니다. 작업 중에는 수시로 저장하세요.
