# 파일 메뉴

파일 메뉴는 프로젝트, 모델, 캔버스, 텍스처를 열고 저장하고 교환하는 기능을 제공합니다.

## 프로젝트

| 기능 | 설명 | 단축키 |
| --- | --- | --- |
| 프로젝트 열기 (`.dpp`) | 이전에 저장한 모델 경로, 캔버스, 레이어, 마스크 상태를 복원합니다. | `Ctrl+Shift+O` |
| 최근 프로젝트 | 최근에 작업한 `.dpp` 파일을 빠르게 엽니다. | - |
| 프로젝트 저장 | 현재 편집 상태를 `.dpp`로 저장합니다. | `Ctrl+S` |
| 다른 이름으로 프로젝트 저장 | 새 파일명이나 위치에 프로젝트 사본을 저장합니다. | `Ctrl+Shift+S` |
| 프로젝트 패키지 내보내기 (`.zip`) | 프로젝트와 관련 리소스를 이동하기 쉬운 패키지로 묶습니다. | - |

`.dpp`는 최종 이미지가 아니라 이어서 편집하기 위한 작업 파일입니다. 모델 파일을 다른 위치로 옮긴 뒤에는 프로젝트에서 모델 경로를 다시 확인하세요.

## 모델과 캔버스

- **모델 불러오기 (.obj/.fbx/.glb)**는 모델과 UV를 엽니다. 모델에 유효한 UV가 있어야 2D 텍스처 작업이 올바르게 표시됩니다.
- **캔버스 설정...**은 재질, 텍스처 슬롯, 캔버스 해상도를 관리합니다.
- **최근 모델**은 최근에 불러온 모델 목록을 제공합니다.

## 내보내기와 교환

- **Export Model (.fbx/.obj)...**는 작업한 모델을 OBJ 또는 FBX로 저장합니다.
- **이미지 내보내기...**는 선택한 텍스처의 합성 결과를 이미지로 저장합니다.
- **OpenRaster 가져오기/내보내기 (.ora)**는 레이어 구조를 다른 이미지 편집 프로그램과 주고받을 때 사용합니다.

자세한 형식별 주의사항은 [저장 및 내보내기](시작하기/저장 및 내보내기.md)를 참고하세요.
