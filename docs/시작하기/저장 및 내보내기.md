# 저장 및 내보내기

## 프로젝트 저장: `.dpp`

**파일 > 프로젝트 저장 (.dpp)** 또는 `Ctrl+S`로 현재 프로젝트를 저장합니다. 처음 저장하거나 사본이 필요하면 **파일 > 다른 이름으로 프로젝트 저장 (.dpp)...** (`Ctrl+Shift+S`)를 사용하세요.

`.dpp`는 델피아 전용 프로젝트 형식입니다. 모델 경로, 캔버스와 레이어, 마스크 등 편집 상태를 보관하므로 이어서 작업할 원본으로 사용합니다. 모델 파일을 옮기거나 교체하면 프로젝트에서 모델 위치를 다시 찾아야 할 수 있습니다.

## 이미지 내보내기

**파일 > 이미지 내보내기...** 또는 `Ctrl+Shift+E`를 선택합니다. 선택한 텍스처의 합성 결과를 PNG, JPEG, TGA로 저장할 수 있습니다. 투명도가 필요하면 PNG 또는 TGA를 사용하세요. 내보내기 전에는 올바른 재질과 텍스처 슬롯을 선택했는지 확인하세요.

## OpenRaster: `.ora`

**파일 > OpenRaster 내보내기 (.ora)...**는 레이어와 그룹 구조를 포함하는 OpenRaster 파일을 만듭니다. Krita, GIMP 등과 레이어 작업을 주고받을 때 유용합니다. **파일 > OpenRaster 가져오기 (.ora)...**로 다시 가져올 수 있지만, 다른 프로그램의 모든 레이어 속성이나 효과가 동일하게 재현되지는 않을 수 있습니다.

## 모델 내보내기

**파일 > Export Model (.fbx/.obj)...**에서 모델을 OBJ 또는 FBX로 내보낼 수 있습니다. 텍스처 포함 방식을 확인하고, 모델과 생성된 텍스처를 같은 폴더 구조로 보관하세요.

## ORA를 가져올 때의 적용 방식

ORA 가져오기는 파일명과 현재 캔버스 이름이 같은지와 무관하게 선택한 방식으로 적용합니다.

- **현재 레이어 덮어쓰기**: 현재 캔버스의 레이어를 ORA 레이어들로 교체합니다. 원래 작업이 필요하면 먼저 프로젝트 사본을 저장하세요.
- **최상단 그룹으로 추가**: 기존 레이어를 유지하면서 가져온 레이어들을 새 최상단 그룹에 넣습니다.
- **취소**: 가져오기를 적용하지 않습니다.

현재 Lite에서도 그룹 추가 경로를 사용할 수 있습니다. 예전의 그룹·5개 레이어 제한 때문에 항상 한 장으로 합쳐 가져온다는 설명은 현재 동작과 다릅니다.

## 생성 결과도 따로 보관하기

필터 미리보기나 AO 베이크 작업창의 결과를 영구 원본처럼 취급하지 마세요. 필터는 확인으로 적용한 뒤 프로젝트를 저장하고, AO는 레이어로 추가해 저장하거나 작업창의 PNG 내보내기로 보관합니다.

브러시 설정 공유는 프로젝트·ORA가 아니라 [브러시 패키지](../도구/브러시%20및%20지우개.md)의 `.dbrush` 내보내기를 사용합니다.
