# 프로젝트 세팅

---

## 이 프로그램의 프로젝트를 시작하는 방법은 다음과 같습니다.

- **"파일 - 새 모델 불러오기"** 메뉴를 클릭하여 obj나 fbx파일을 불러옵니다.
- 모델을 불러오면 모델에 포함된 메테리얼 수만큼 목록이 표시되고, 각 목록마다 Albedo, Emission 캔버스를 할당할 수 있는 슬롯이 배정됩니다.
- 작업할 슬롯에 원하는 사이즈의 캔버스를 배치하고, 확인을 누르면 새 프로젝트가 활성화됩니다.

- 현재 편집중인 캔버스를 전환하는 건 이 메테리얼 패널에서 가능합니다.
- 아무런 캔버스도 할당되지 않은 슬롯은 이렇게 빗금처리가 되고, 클릭이나 우클릭을 통해 원하는 사이즈의 캔버스를 지정해줄 수 있습니다. 반대로 우클릭 - 연결해제를 눌러 캔버스를 제거할 수도 있습니다.
- 선택중인 캔버스에는 이런 식으로 표시됩니다. 혹은 중앙 작업영역 상단에서도 현재 편집 중인 캔버스를 확인하거나 전환할 수 있습니다.


## 베이스 컬러를 작업할 캔버스는 Albedo, Emission 둘 중 원하는 걸로 해도 상관없습니다. 다만, 권장하는 방식은 Albedo 캔버스에서 작업하는 방식입니다.
- 해당 툴은 미리보기용으로 **Bloom** 환경 옵션을 제공합니다. 다만, 이 Bloom에 영향받는 건 오로지 Emission 슬롯에 할당된 캔버스의 색상뿐입니다.
- 즉, 특정 부위만 빛나는 랜턴이나, 빛나는 마법진이 새겨진 룬과 같이 특정 부위가 발광하는 효과를 얻고 싶다면, Albedo에서 베이스 컬러 페인팅을 하고, 발광원만 Emission에서 처리를 하는 편이 좋습니다.
