# 기본 조작법

이 페이지는 자주 쓰는 단축키와 보기 조작을 빠르게 확인하는 용도입니다. 2D와 3D 뷰의 역할 및 작업 흐름은 [2D와 3D 작업](2D와 3D 작업.md)을 참고하세요.

## 기본 도구

- 브러시: `B`
- 지우개: `E`
- 채우기/그라디언트: `G`
- 선택 도구 전환: `M`
- 레이어 마스크 잠깐 보기: `Q`
- 실행 취소/다시 실행: `Ctrl+Z` / `Ctrl+Shift+Z`

브러시·지우개 설정과 프리셋 관리는 [브러시 및 지우개](../도구/브러시 및 지우개.md)를, 선택과 변형은 [선택과 변형](../편집/선택과 변형.md)을 참고하세요.

## 화면 이동

2D 뷰는 확대·이동·회전을 지원합니다. 보기 상태 초기화 단축키는 `Alt+R`(회전), `Alt+G`(이동), `Alt+S`(확대)입니다. 창 배치와 패널 표시는 `창` 메뉴에서 조절합니다.
