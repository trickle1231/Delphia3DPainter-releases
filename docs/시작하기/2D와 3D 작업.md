# 2D와 3D 작업

델피아 3D 페인터는 같은 활성 텍스처를 **2D**와 **3D** 방식으로 편집합니다. 한쪽에서 만든 획, 레이어, 마스크와 선택 결과는 다른 쪽에도 반영됩니다. 상단 보기 모드에서 2D만, 3D만 또는 `2D + 3D` 분할 보기를 선택할 수 있습니다.

## 언제 어느 뷰를 쓰나요?

| 작업 목적 | 권장 뷰 | 이유 |
| --- | --- | --- |
| UV 섬 경계, 이음새, 작은 픽셀 보정 | 2D | 텍스처 픽셀과 UV 오버레이를 직접 볼 수 있습니다. |
| 모델 표면에 큰 색과 질감 배치 | 3D | UV를 외우지 않고 보이는 표면에 바로 칠할 수 있습니다. |
| 최종 색 확인 | 3D | Lit/Unlit, 와이어프레임, 환경 미리보기로 결과를 점검할 수 있습니다. |

2D에서는 선택 영역이 픽셀을 대상으로 하고, 3D에서는 화면의 선택 범위와 겹치는 모델 면을 대상으로 합니다. 이 차이는 선택 기반의 브러시·채우기·마스크 작업에도 그대로 적용됩니다. 자세한 선택 방법은 [선택과 변형](../편집/선택과 변형.md)을 참고하세요.

## 함께 쓰는 기본 흐름

1. 3D 뷰에서 모델 표면에 큰 색과 질감을 빠르게 칠합니다.
2. 2D 뷰에서 UV 이음새와 작은 디테일을 보정합니다.
3. 3D 뷰에서 Lit/Unlit과 와이어프레임을 바꿔 결과를 점검합니다.
4. 선택·마스크·필터 작업 뒤에는 두 뷰를 오가며 의도하지 않은 영역이 바뀌지 않았는지 확인합니다.

2D·3D 보기 조작은 [기본 조작법](기본 조작법.md), 패널과 표시 옵션은 [화면과 패널](화면과 패널.md), 도구별 조작은 아래 기능 문서를 참고하세요.

- [브러시 및 지우개](../도구/브러시 및 지우개.md)
- [채우기와 그라디언트](../도구/채우기와 그라디언트.md)
- [선택과 변형](../편집/선택과 변형.md)

3D에서 칠할 때 `편집 중인 메테리얼이 아닙니다`라는 안내가 나오면, 해당 표면이 현재 선택된 텍스처 캔버스와 연결된 재질인지 확인한 뒤 재질 또는 캔버스를 바꾸세요.
