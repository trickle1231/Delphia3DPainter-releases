# 화면과 패널

델피아 3D 페인터는 가운데의 2D UV 뷰와 3D 모델 뷰, 그리고 도킹 가능한 패널로 구성됩니다. 패널은 `창` 메뉴에서 표시하거나 숨길 수 있으며, `창 > 레이아웃`에서 작업 목적에 맞게 배치할 수 있습니다.

## 뷰 영역

### 2D 텍스처 뷰

현재 활성 캔버스의 UV 텍스처를 픽셀 단위로 편집하는 영역입니다. 2D·3D 뷰의 작업 차이와 권장 흐름은 [2D와 3D 작업](2D와 3D 작업.md)을 참고하세요.

### 3D 모델 뷰

모델 표면에 직접 칠하고 결과를 확인하는 영역입니다. 재질·환경 설정과 함께 최종 표현을 점검하고, 3D 면 선택으로 작업할 부분을 제한할 수 있습니다.

## 기본 도킹 패널

### 레이어 패널

현재 캔버스의 레이어 순서와 상태를 관리합니다. 레이어를 선택하고 표시 여부, 불투명도, 혼합 모드, 잠금을 바꾸며 그룹과 마스크를 관리합니다. 페인팅 전에는 이 패널에서 작업 대상 레이어가 맞는지 확인하세요.

### 브러시 목록

브러시와 지우개 프리셋을 선택하는 패널입니다. 패널 메뉴에서 프리셋 추가, 복제, 이름 변경, 삭제, JSON 가져오기·내보내기와 기본 프리셋 복원을 사용할 수 있습니다. 자주 쓰는 도구 조합을 프리셋으로 관리하면 작업 속도가 빨라집니다.

### 브러시 설정

선택한 브러시 또는 지우개의 세부 값을 조절합니다. 기본 설정에서 크기·경도·간격을 조절하고, 탭에서 팁 모양, 압력 등 획의 성질을 조정합니다. 설정 변경은 현재 선택된 프리셋과 도구 동작에 반영됩니다.

### 메테리얼/환경

두 탭으로 나뉩니다.

- 메테리얼: 모델의 재질별 표시·격리와 재질 관련 표현을 관리합니다. 여러 재질이 있는 모델에서 특정 재질만 확인할 때 유용합니다.
- 환경: 3D 배경색과 그림자색, Bloom 사용 여부·강도·반경·임계값·Knee를 조절합니다. 이 설정은 3D 미리보기의 표현을 위한 것이므로, 텍스처 이미지 자체를 직접 수정하지는 않습니다.

### 컬러 서클

브러시의 전경색과 배경색을 정하는 패널입니다. 패널 메뉴에서 HSV/HSL 색상 모델과 원형·사각·삼각·슬라이더·OKLCH 색상 형태를 고를 수 있습니다. `X`는 전경색과 배경색을 바꾸고, `C`는 투명 잉크를 전환합니다.

### Color Palette

자주 쓰는 색을 모아 두고 선택하는 팔레트 패널입니다. 컬러 서클과 탭으로 전환해 사용할 수 있습니다.

## 보조 패널과 대화상자

### 캔버스 설정

`파일 > 캔버스 설정...`에서 재질과 텍스처 캔버스의 연결을 확인하고 변경합니다. 재질-캔버스와 캔버스 목록 탭이 있으며, 새 캔버스 생성·이미지 불러오기·할당에 사용합니다.

### 소스 브라우저

`창 > 소스 브라우저`에서 브러시 팁과 소스 텍스처를 관리합니다. 등록한 소스는 브러시 팁 또는 소스 텍스처 레이어로 재사용할 수 있습니다.

### 아카이브

`창 > 아카이브`는 텍스처와 관련 소스를 보관·재사용하는 작업 공간입니다. 현재 캔버스에 연결된 파일을 바꾸기 전에 보관본을 남겨두는 용도로 활용할 수 있습니다.

### 베이크 패널

`베이크 > 베이크 패널...`에서 AO, Curvature, Cavity 맵을 생성합니다. 자세한 내용은 [베이크](../도구/베이크.md)를 참고하세요.
