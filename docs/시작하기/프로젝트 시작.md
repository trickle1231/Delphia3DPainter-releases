# 프로젝트 시작

## 1. 모델 불러오기

`파일 > 모델 불러오기 (.obj/.fbx)...`를 선택하거나 `Ctrl+O`를 누릅니다. 델피아 3D 페인터는 모델의 UV를 이용해 텍스처를 표시하고 3D 표면에 칠합니다. 따라서 작업 전에 모델에 유효한 UV가 있는지 확인하세요.

모델을 연 뒤에는 `파일 > 캔버스 설정...`에서 재질별 텍스처 슬롯을 확인하고 필요한 캔버스를 연결합니다. 임베디드 텍스처가 없는 모델은 이미지 파일을 불러오거나 해상도 드롭다운에서 캔버스 크기를 고를 수 있습니다.

새 캔버스의 해상도는 `128`, `256`, `512`, `1024`, `2048`, `4096`px 중에서 선택합니다. 체험판에서는 `1024`px 이하만 표시됩니다. 이 규칙은 캔버스 설정, 재질 패널의 새 캔버스 추가, 일괄 할당에도 동일하게 적용됩니다.

## 2. 작업 흐름

1. 재질과 텍스처 슬롯을 선택합니다.
2. 래스터 레이어를 추가합니다.
3. 2D UV 뷰 또는 3D 뷰에서 칠합니다. 두 뷰의 쓰임과 전환 기준은 [2D와 3D 작업](2D와 3D 작업.md)을 참고하세요.
4. 필요하면 선택·마스크·필터로 수정합니다.
5. `.dpp` 프로젝트로 저장하고, 완료본은 이미지로 내보냅니다. 형식별 저장 방법은 [저장 및 내보내기](저장 및 내보내기.md)를 참고하세요.

다른 모델이나 프로젝트로 전환할 때 저장되지 않은 변경 사항이 있으면 저장 여부를 확인합니다.
