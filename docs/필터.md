# 필터 메뉴

필터는 현재 캔버스의 **편집 가능한 래스터 레이어 한 개**를 대상으로 합니다. 색상 조정, 블러 / 왜곡, 노이즈 / 생성의 세 하위 메뉴로 구분됩니다. 레이어 오른쪽 클릭 메뉴에도 같은 분류가 있습니다.

## 메뉴 구성

| 분류 | 필터 | 용도 | 기본 단축키 |
| --- | --- | --- | --- |
| 색상 조정 | 색 반전 | RGB 색을 반전합니다. | 없음 |
| 색상 조정 | HSV 조정 | 색조·채도·명도를 조정합니다. | `Ctrl+U` |
| 색상 조정 | 톤 커브 | 밝기 또는 RGB 채널별 곡선을 조정합니다. | `Ctrl+M` |
| 색상 조정 | 컬러 밸런스 | 그림자·중간톤·하이라이트의 색 균형을 조정합니다. | 없음 |
| 색상 조정 | 레벨 | 입력 검정·중간톤·흰점과 출력 범위를 조정합니다. | `Ctrl+L` |
| 색상 조정 | 그라디언트 맵 | 원본 밝기를 어두운색·중간색·밝은색으로 재배색합니다. | 없음 |
| 색상 조정 | 노출 / 대비 | 전체 노출과 대비를 조정합니다. | 없음 |
| 색상 조정 | 색온도 / 틴트 | 차갑게/따뜻하게, 초록/자홍 방향으로 색감을 조정합니다. | 없음 |
| 색상 조정 | 그림자 / 하이라이트 | 어두운 부분과 밝은 부분을 따로 조정합니다. | 없음 |
| 블러 / 왜곡 | 경사 블러 | 내장 노이즈의 기울기를 따라 색을 여러 번 샘플링합니다. | 없음 |
| 블러 / 왜곡 | 워프 | 일반·방향·다방향 변형을 적용합니다. | 없음 |
| 노이즈 / 생성 | 일반 노이즈 추가 | 픽셀 단위의 무작위 질감을 더하거나 생성합니다. | 없음 |
| 노이즈 / 생성 | 펄린 노이즈 | 부드럽게 이어지는 다중 스케일 노이즈를 생성합니다. | 없음 |

단축키는 기본값입니다. [환경설정](환경설정.md)에서 변경했다면 사용자 설정이 우선합니다.

## 실행 전 확인

- 활성 캔버스와 래스터 레이어가 있어야 합니다.
- 상단 메뉴에서는 활성 레이어와 선택한 레이어가 일치해야 하며, 한 개만 선택해야 합니다.
- 레이어 또는 상위 그룹이 숨겨졌거나 잠겨 있으면 먼저 표시·잠금 상태를 바꾸세요.
- 그룹·채우기·소스 텍스처 레이어에 직접 적용하는 기능이 아닙니다.
- 마스크 편집 중에는 필터 메뉴를 사용할 수 없습니다. 마스크 편집을 마친 뒤 레이어 본문을 대상으로 실행하세요.
- 대화상자형 고급 필터는 Pro 기능입니다. Lite 제한은 [라이선스 관리](라이선스%20관리.md)를 참고하세요.

필터는 조정 레이어나 계속 수정할 수 있는 비파괴 효과 스택을 만드는 기능이 아닙니다. 결과를 확정하면 대상 레이어의 픽셀이 변경됩니다. 비교할 원본은 복제하거나 프로젝트 사본으로 보관하세요.
