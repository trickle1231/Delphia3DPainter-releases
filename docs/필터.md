# 필터 메뉴

필터 메뉴의 명령은 활성 래스터 레이어에 적용됩니다. 선택 영역이 있으면 선택된 부분만 처리하며, 그룹 레이어와 잠긴 레이어에는 적용할 수 없습니다.

| 기능 | 설명 | 단축키 |
| --- | --- | --- |
| 색 반전 | 각 픽셀의 색상 방향을 반대로 바꿉니다. | - |
| HSV 조정 | 색상, 채도, 명도를 조절합니다. | `Ctrl+U` |
| 톤 커브 | 입력 밝기와 출력 밝기의 관계를 곡선으로 조절합니다. | `Ctrl+M` |
| 컬러 밸런스 | 그림자, 중간톤, 밝은 영역의 색 균형을 조절합니다. | - |
| 레벨 | 검정점, 중간톤, 흰점을 조절해 대비를 정리합니다. | `Ctrl+L` |

HSV, 톤 커브, 컬러 밸런스, 레벨은 미리보기 대화상자에서 확인한 뒤 적용하거나 취소할 수 있습니다. 필터는 픽셀 데이터를 변경하므로 적용 전에 `.dpp` 저장 또는 레이어 복사를 권장합니다.

전체 옵션과 마스크 편집 중 필터의 동작은 [필터 사용법](편집/필터.md)을 참고하세요.
