# 베이크 메뉴

현재 상단 메뉴의 베이크 항목은 **AO Bake...**이며 기본 단축키는 `Ctrl+Alt+B`입니다. 전체 화면의 AO 전용 GPU Bake V2 작업창을 엽니다.

## 현재 제공 범위

- 불러온 모델의 재질을 선택해 AO를 생성합니다.
- 512, 1024, 2048, 4096 정사각 출력 해상도를 제공합니다.
- 결과는 재질별로 미리 보고 PNG로 저장할 수 있습니다.
- 작업창을 닫은 뒤 레이어 패널의 추가 메뉴에서 **베이크 레이어 추가 > AO (GPU Bake V2)**로 가져올 수 있습니다.
- Lite에서도 작업창을 열 수 있습니다.

이전 문서의 **베이크 패널...**, **Curvature / Cavity 선택**, **AO 반경·강도·레벨 조절**, **하이폴리 소스 불러오기**는 현재 연결된 AO Bake V2 화면의 옵션이 아닙니다. 예전 패널 코드가 남아 있어도 현재 메뉴에서 제공하는 기능으로 안내하지 않습니다.

## 작업 전 확인

1. OBJ 또는 FBX 모델을 불러오고 UV와 재질 이름을 확인합니다.
2. 프로젝트를 저장합니다.
3. 작업창에서 베이크할 재질을 체크합니다.
4. 우선 낮은 해상도로 결과를 확인한 뒤 최종 해상도를 정합니다.
5. 결과를 PNG로 보관하거나 현재 캔버스에 새 AO 레이어로 추가합니다.

GPU 계산 중에는 UI 응답과 취소가 지연될 수 있습니다. 상세 절차와 제한은 [AO 베이크 작업](도구/베이크.md)을 참고하세요.
