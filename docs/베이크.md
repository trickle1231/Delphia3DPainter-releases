# 베이크 메뉴

`베이크 > 베이크 패널...`을 열어 모델의 표면 정보를 텍스처로 굽는 작업을 설정합니다. 단축키는 `Ctrl+Alt+B`입니다.

## 베이크를 사용하기 전

1. 모델을 불러오고 UV와 대상 재질을 확인합니다.
2. 프로젝트를 저장해 원본 상태를 보존합니다.
3. 베이크 패널에서 소스와 대상, 출력 텍스처 설정을 확인합니다.
4. 결과를 미리 확인한 뒤 캔버스 또는 레이어에 적용합니다.

베이크 결과를 페인팅 결과와 분리해 관리하려면 별도 래스터 레이어로 추가하세요. 베이크 기능은 체험판에서 사용할 수 없을 수 있습니다.

세부 옵션과 문제 해결은 [베이크 작업](도구/베이크.md)을 참고하세요.
