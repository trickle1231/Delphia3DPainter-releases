# 업데이트 확인

**도움말 > 업데이트 확인...**을 선택하면 현재 설치된 버전을 서버의 최신 버전 정보와 비교합니다. 업데이트 확인에는 인터넷 연결이 필요합니다.

## 결과

- **최신 버전인 경우**: 현재 사용 중인 버전 번호와 함께 최신 버전이라는 안내가 표시됩니다.
- **새 버전이 있는 경우**: 최신 버전 번호와 릴리스 노트가 표시됩니다. **설치 페이지 열기**를 누르면 다운로드 페이지가 브라우저에서 열립니다.
- **확인에 실패한 경우**: 서버에 연결할 수 없거나 응답을 읽을 수 없다는 안내가 표시됩니다. 인터넷 연결을 확인한 뒤 다시 시도하세요.

이 기능은 앱 안에서 자동 설치를 수행하지 않습니다. 다운로드 페이지에서 설치 파일을 받은 뒤, 진행 중인 작업을 저장하고 설치 프로그램의 안내에 따라 업데이트하세요.

## 자동 안내와 수동 확인

앱 시작 흐름에서도 서버의 업데이트 정보를 확인할 수 있습니다. 같은 최신 버전과 같은 공지 갱신 시점의 안내는 반복 표시를 줄이기 위해 기록됩니다. 안내를 닫았더라도 **도움말 > 업데이트 확인...**에서 직접 확인할 수 있습니다.

표시 결과는 서버에 설정된 최신 버전·안내 활성화 여부를 기준으로 합니다. “최신 버전”이라는 안내가 모든 외부 다운로드 사이트나 개발 중 빌드를 검색한 결과를 뜻하지는 않습니다.

설치 페이지 주소는 서버 응답의 다운로드 주소를 우선 사용하며, 없으면 앱 설정의 주소를 사용합니다. 기본 안내 경로는 [다운로드](https://delphia-painter-links.web.app/download)입니다.

업데이트 확인과 라이선스 인증은 별도입니다. 업데이트를 확인했다고 Pro가 인증되거나, 프로그램 파일이 자동 교체되지는 않습니다.
