# 편집 메뉴

편집 메뉴는 작업 결과를 되돌리고 다시 적용하거나, 선택을 해제하고 앱 설정을 여는 메뉴입니다.

| 기능 | 설명 | 단축키 |
| --- | --- | --- |
| 실행 취소 | 최근 페인팅, 레이어, 선택 등의 편집을 이전 상태로 되돌립니다. | `Ctrl+Z` |
| 다시 실행 | 실행 취소한 작업을 다시 적용합니다. | `Ctrl+Shift+Z` |
| 선택 해제 | 현재 2D 픽셀 선택 또는 3D 면 선택을 제거합니다. | `Ctrl+D` |
| 환경설정... | 언어, 테마, 안내선, 단축키, 수식키를 설정합니다. | `Ctrl+,` |

## 사용 순서

1. 결과가 마음에 들지 않으면 `실행 취소`를 사용합니다.
2. 되돌린 작업을 다시 살리려면 `다시 실행`을 사용합니다.
3. 선택 범위가 남아 있어 다음 작업이 제한되면 `선택 해제`를 실행합니다.
4. 반복해서 사용할 단축키나 표시 색상은 [환경설정](환경설정.md)에서 조정합니다.

필터와 레이어 병합처럼 되돌리기 어려운 작업 전에는 프로젝트를 저장하거나 레이어를 복제해 두는 것이 좋습니다.
