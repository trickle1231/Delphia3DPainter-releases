# 환경설정

**편집 > 환경설정...** 또는 `Ctrl+,`에서 앱 전반의 설정을 변경합니다. 설정을 바꾼 뒤 **Apply** 또는 **OK**를 눌러 저장합니다. **Cancel**은 적용하지 않은 변경을 되돌립니다.

## 일반

| 항목 | 설명 |
| --- | --- |
| 언어 | 한국어, English, 日本語를 선택합니다. 언어 변경 후에는 앱을 다시 시작해야 새 언어가 적용됩니다. |
| AppData 폴더 열기 | 브러시 프리셋, 소스 텍스처, 테마, 설정 등 앱 데이터가 저장된 폴더를 엽니다. |
| 백업 내보내기 | 앱 데이터와 설정을 `.dpbak` 백업 파일로 저장합니다. 다른 PC로 옮기거나 설정을 초기화하기 전 보관할 때 사용합니다. |
| 백업 가져오기 | `.dpbak` 파일을 가져와 같은 이름의 앱 데이터를 덮어씁니다. 가져온 뒤 앱이 자동으로 다시 시작됩니다. 먼저 현재 프로젝트를 저장하세요. |
| 모든 데이터 초기화 | 캐시, 환경설정, 브러시 설정, 기본 프리셋을 초기 상태로 되돌린 뒤 앱을 다시 시작합니다. 라이선스와 프로젝트 파일, 사용자가 직접 가져온 소스 파일은 유지됩니다. |

캔버스 이름 규칙 항목은 내부에 저장되지만 현재 화면에서는 표시되지 않습니다. 텍스처 슬롯 기반 작업 흐름에서는 캔버스 이름을 직접 정하는 기능을 사용하지 않습니다.

## 테마

**테마 갤러리 열기...**에서 기본 테마 프리셋을 골라 앱의 색상 구성을 바꿉니다. 최근에 사용한 테마와 개별 색상·테마 파일 가져오기/저장·캔버스 윤곽선 강도 기능은 내부적으로 준비되어 있으나 현재 환경설정 화면에는 표시되지 않습니다.

## 브러시

환경설정의 브러시 탭은 현재 “준비 중” 안내만 표시합니다. 실제 브러시 프리셋과 세부 속성은 [브러시 및 지우개](도구/브러시 및 지우개.md) 패널에서 설정하세요.

## 격자 및 안내선

작업 표시용 선의 색과 투명도를 테마와 별개로 조절합니다.

| 항목 | 설명 |
| --- | --- |
| 3D 격자 색상 / 불투명도 | 3D 뷰 바닥 격자의 색과 표시 강도를 정합니다. |
| 2D 안내선 색상 / 불투명도 | 2D 뷰의 안내선 색과 표시 강도를 정합니다. |
| UV 와이어프레임 색상 | 2D 텍스처 뷰에서 UV 오버레이 선의 색을 정합니다. |
| 3D 와이어프레임 색상 | 3D 뷰에서 메시 와이어프레임을 표시할 때 사용하는 색을 정합니다. |
| 레이어 마스크 와이어프레임 색상 | 3D에서 마스크 편집·표시와 관련된 와이어프레임 색을 정합니다. |
| 색상 초기화 | 위 색상들을 기본값으로 되돌립니다. |

색상과 불투명도 변경은 대화상자에서 즉시 미리보기로 반영됩니다.

## 단축키

모든 메뉴·도구 단축키를 기능별로 보고 바꿀 수 있습니다. 파일, 편집, 레이어, 2D 보기, 3D 보기, 선택·변형, 페인팅, 필터, 베이크, 도움말 등의 그룹으로 나뉩니다.

- 키 입력 칸을 선택한 뒤 원하는 단일 키 또는 조합을 누릅니다.
- **지우기**는 해당 기능의 단축키를 제거합니다.
- **기본값**은 해당 기능만 기본 단축키로 되돌립니다.
- **모두 기본값으로**는 전체 단축키를 초기화합니다.

같은 동작 범위에서 중복된 단축키는 저장할 수 없습니다. 2D 전용과 3D 전용 동작처럼 범위가 다른 경우는 같은 키를 사용할 수 있습니다.

## 수식키

수식키 탭에서는 Shift, Ctrl, Alt 같은 키를 뷰 탐색 동작에 할당합니다. 각 동작은 **없음**, **Ctrl**, **Shift**, **Alt**, **Ctrl 또는 없음** 중 하나로 정할 수 있습니다.

| 범위 | 설정 가능한 동작 |
| --- | --- |
| 2D 뷰 | 휠 확대/축소, Space 드래그 이동, Space 드래그 회전, Space 드래그 확대/축소 |
| 3D 뷰 | 뷰 이동, 돌리(줌) |

각 행의 **기본값**은 해당 동작만 초기화하고, **모두 기본값으로**는 모든 수식키 할당을 초기화합니다. 같은 뷰 범위에서 동일한 수식키를 여러 동작에 중복 지정하면 저장할 수 없습니다.
