# 창 메뉴

창 메뉴는 캔버스와 보조 패널을 열고 화면 배치를 관리합니다.

| 기능 | 설명 |
| --- | --- |
| 캔버스 설정... | 재질별 텍스처 슬롯과 캔버스 해상도를 관리합니다. |
| 아카이브 | 작업 기록 또는 보관 관련 패널을 엽니다. |
| 소스 브라우저 | 등록된 소스 텍스처와 리소스를 관리합니다. |
| 레이아웃 관리... | 화면 배치를 저장하고 불러올 레이아웃을 관리합니다. |
| 레이아웃 초기화 | 기본 패널 배치로 되돌립니다. |

메뉴 아래에는 현재 앱에 등록된 도킹 패널을 표시하거나 숨기는 항목도 나타납니다. 패널을 닫았거나 위치가 꼬였을 때 `레이아웃 초기화`를 사용하세요.

화면 구성과 각 패널의 역할은 [화면과 패널](시작하기/화면과 패널.md)에 설명되어 있습니다.
