# 도움말 메뉴

도움말 메뉴는 사용 안내, 라이선스, 업데이트, 앱 정보를 확인하는 기능을 제공합니다.

| 기능 | 설명 | 단축키 |
| --- | --- | --- |
| 도움말 | 온라인 도움말을 엽니다. | `F1` |
| 라이선스 관리... | 라이선스 상태와 활성화된 기기를 관리합니다. | - |
| 업데이트 확인... | 새 버전이 있는지 확인합니다. | - |
| 개발자 정보... | 앱의 개발자 및 빌드 정보를 확인합니다. | - |

트라이얼 상태에서는 라이선스에 따라 베이크나 일부 고급 필터 기능이 제한될 수 있습니다. 제한 상태가 예상과 다르면 `라이선스 관리...`에서 현재 라이선스를 확인한 뒤 업데이트를 다시 확인하세요.
