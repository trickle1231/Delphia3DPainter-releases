# 도움말 메뉴

도움말 메뉴에서는 온라인 문서·영상·커뮤니티를 열거나, 라이선스와 업데이트 상태를 확인합니다.

| 기능 | 동작 | 기본 단축키 |
| --- | --- | --- |
| Docs | 기본 웹 브라우저에서 온라인 위키를 엽니다. | `F1` |
| YouTube | 개발자 YouTube 채널을 브라우저에서 엽니다. | 없음 |
| 디스코드 / Discord | Discord 초대 링크를 브라우저에서 엽니다. | 없음 |
| 라이선스 관리... | Lite / Pro 상태 확인, 인증, 연결된 기기 해제를 수행합니다. | 없음 |
| 업데이트 확인... | 현재 버전과 서버의 최신 버전을 비교합니다. | 없음 |
| 개발자 정보... | 개발자 및 앱 정보를 확인합니다. | 없음 |

이전 문서의 **도움말** 항목 이름은 현재 **Docs**입니다. `F1`은 그대로 온라인 문서를 엽니다. Docs·YouTube·Discord는 앱 안에서 게시글 목록을 조회하는 창이 아니라, 해당 웹 주소를 직접 여는 기능입니다.

## 고정 안내 주소

앱의 외부 안내 링크는 Firebase Hosting의 고정 경로를 거쳐 실제 사이트로 이동합니다.

| 용도 | 안내 링크 |
| --- | --- |
| 문서 | [Docs](https://delphia-painter-links.web.app/docs) |
| 영상 | [YouTube](https://delphia-painter-links.web.app/youtube) |
| 커뮤니티 | [Discord](https://delphia-painter-links.web.app/discord) |
| 설치 파일 | [다운로드](https://delphia-painter-links.web.app/download) |
| 구매 안내 | [구매](https://delphia-painter-links.web.app/purchase) |
| 의견·문제 제보 | [피드백](https://delphia-painter-links.web.app/feedback) |

안내 경로의 실제 목적지는 운영 중 변경될 수 있습니다. 이 표의 모든 링크가 도움말 메뉴의 개별 버튼이라는 뜻은 아닙니다.

## 링크가 열리지 않을 때

- 인터넷 연결과 기본 웹 브라우저 설정을 확인합니다.
- 브라우저에서 위 안내 링크를 직접 열어 앱의 링크 실행 문제인지, 웹 사이트의 문제인지 구분합니다.
- Firebase의 **Page Not Found**가 보이면 운영자가 해당 경로의 배포 상태를 확인해야 합니다. 로컬 설정 파일만 수정했다고 서비스에 반영되는 것은 아닙니다.
- Discord 초대가 만료됐거나 목적지 사이트가 이동한 경우에는 운영자에게 경로와 오류 화면을 알려주세요.
- 문제 제보 시 관리자 키, 라이선스 키 원문, 개인정보가 보이는 화면은 첨부하지 마세요.

라이선스 제한이 예상과 다르면 [라이선스 관리](라이선스%20관리.md)를, 새 버전 설치 방법은 [업데이트 확인](업데이트%20확인.md)을 참고하세요. 업데이트 확인만으로 라이선스가 인증되거나 제한이 해제되지는 않습니다.
