# 라이선스 관리

**도움말 > 라이선스 관리...**에서 현재 라이선스 상태를 확인하고, 이 PC의 라이선스를 인증하거나 해제할 수 있습니다. 라이선스 키가 이미 등록되어 있다면 이 메뉴를 열 때 상태를 다시 확인합니다.

## 첫 실행: 라이선스 인증 또는 체험판 시작

라이선스 키가 등록되지 않은 상태로 처음 실행하면 라이선스 입력 창이 열립니다. 여기에서 라이선스 키와 선택 사항인 기기 이름을 입력해 **Activate**를 누르면 이 PC에서 인증을 시도합니다. 키를 아직 입력하지 않으려면 **Continue Trial**을 선택해 체험판으로 시작할 수 있습니다.

처음 실행 시 인터넷에 연결되어 있지 않거나 인증에 실패해도 앱은 체험판으로 계속 실행됩니다. 이후 인터넷에 연결되었을 때 다시 인증할 수 있으며, **도움말 > 라이선스 관리...**에서도 같은 작업을 수행할 수 있습니다.

## 상태 확인

대화상자 상단에는 다음 상태 중 하나가 표시됩니다.

- **Licensed**: 현재 PC에서 라이선스가 인증된 상태입니다.
- **Applying license...**: 등록된 키의 상태를 확인 중입니다.
- **Trial**: 라이선스 없이 체험판으로 실행 중입니다.

인증된 상태에서는 연결된 기기 목록에서 기기 이름과 현재 PC 여부를 확인할 수 있습니다.

## 라이선스 인증

1. **도움말 > 라이선스 관리...**를 엽니다.
2. 라이선스 키를 입력합니다.
3. 필요하면 기기 이름을 입력합니다.
4. **Activate**를 눌러 인증합니다.

인증에는 인터넷 연결이 필요합니다. 네트워크에 연결할 수 없으면 체험판은 계속 사용할 수 있으며, 이미 인증된 상태였다면 이전 상태가 유지됩니다. 기기 수 제한에 도달했다면 연결된 기기를 해제한 뒤 다시 시도하세요.

## 기기 해제

연결된 기기 목록의 **Release**로 특정 기기의 인증을 해제할 수 있습니다. 현재 PC를 해제하려면 하단의 **Release This Device**를 사용합니다. 현재 PC를 해제하면 앱이 종료되므로, 작업 중인 프로젝트를 먼저 저장하세요.

새 PC로 옮기기 전에는 기존 PC에서 이 기능으로 인증을 해제하는 것이 좋습니다.

## 체험판 제한

체험판에서는 다음 기능이 제한됩니다.

- 텍스처 최대 크기 1024px (2048/4096 설정 불가)
- 레이어 그룹 사용 불가
- 일반 레이어 최대 5개
- 고급 필터 효과 사용 불가
- Simple AO, Curvature, Cavity 맵 베이크 사용 불가
