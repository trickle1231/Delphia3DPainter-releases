# 라이선스 관리

**도움말 > 라이선스 관리...**에서 현재 **Lite / Pro** 상태를 확인하고 이 PC의 인증 및 연결된 기기를 관리합니다. 예전 문서의 Trial / Licensed 대신 현재 화면에서는 Lite / Pro 이름을 사용합니다.

## 처음 실행할 때

키가 등록되지 않았다면 라이선스 입력 창에서 다음 중 하나를 선택할 수 있습니다.

- 라이선스 키와 선택 사항인 기기 이름을 입력하고 **인증 / Activate**를 누릅니다.
- 키가 없다면 **Lite로 계속 / Continue Lite**로 시작합니다.
- **일주일 동안 라이선스 확인 건너뛰기**를 선택할 수 있습니다. 인증을 생략하는 기간 설정이지 Pro 이용권이나 오프라인 인증 기간을 연장하는 기능은 아닙니다.

첫 인증에는 인터넷 연결이 필요합니다. 연결할 수 없으면 Lite 상태로 계속 작업하고, 나중에 라이선스 관리에서 인증할 수 있습니다.

## Lite와 Pro의 현재 차이

| 기능 | Lite | Pro |
| --- | --- | --- |
| 편집 캔버스 최대 크기 | 가로·세로 각각 최대 2048px | 기본 캔버스 선택에 4096px 제공 |
| 대화상자형 고급 이미지 필터 | 사용 제한 | 사용 가능 |
| 버텍스 컬러 선택·채우기 | 사용 제한 | 사용 가능 |
| 텍스처 타일링 | 사용 제한 | 사용 가능 |
| 레이어 그룹 / 일반 레이어 개수 | 과거 그룹 금지·5개 제한은 현재 강제되지 않음 | 사용 가능 |
| 브러시 살포 | 현재 별도 Lite 제한 꺼짐 | 사용 가능 |
| AO Bake V2 작업창 | 사용 가능 | 사용 가능 |

이 표의 해상도는 **편집 캔버스** 기준입니다. 현재 AO Bake V2에는 별도의 512~4096 출력 해상도 목록이 있고 Lite 상태에 따른 목록 제한이 없습니다. 베이크 결과를 레이어로 넣으면 현재 캔버스 크기에 맞춰집니다.

색 반전은 상단 필터 메뉴의 즉시 처리 명령이며 대화상자형 고급 필터와 별도입니다. 레이어 오른쪽 클릭 메뉴 전체의 비활성화 상태와 혼동하지 마세요.

이전 문서의 “1024px까지”, “레이어 5개까지”, “그룹 불가”, “베이크 불가”를 현재 제한으로 적용하지 마세요. 다만 마스크 편집 중에는 라이선스와 무관하게 레이어 구조 변경 등 일부 작업이 잠깁니다.

## 인증 순서

1. 프로젝트를 저장합니다.
2. **도움말 > 라이선스 관리...**를 엽니다.
3. 라이선스 키를 입력하고 필요하면 이 PC를 구분할 기기 이름을 지정합니다.
4. **인증 / Activate**를 누릅니다.
5. 상태가 Pro인지 확인하고 연결된 기기 목록을 확인합니다.

이미 키가 등록되어 있으면 인증된 상태를 표시하고 키 입력란이 비활성화될 수 있습니다. 화면에 키 원문이 보이지 않는다고 인증이 해제된 것은 아닙니다. 다른 키로 전환하려면 현재 기기 해제와 종료 절차를 먼저 확인하세요.

기기 수는 라이선스 정책에 따라 정해집니다. 일반적인 관리자 발급 기본값은 2개이며, 자신의 연결된 기기 목록과 서버 안내를 기준으로 판단하세요.

## 연결된 기기 해제

기기 목록에서 이름과 현재 PC 여부를 확인한 뒤 **해제 / Release**를 사용합니다.

- **다른 PC 해제**: 해당 기기의 시트를 해제합니다. 목록이 바뀌었다는 오류가 나오면 창을 다시 열어 최신 목록에서 선택하세요.
- **현재 PC 해제**: 하단 **이 기기 해제 / Release This Device** 또는 현재 PC 행의 해제를 사용합니다. 정상 해제 후 앱이 종료됩니다.
- 현재 PC 해제 과정에서는 저장되지 않은 프로젝트를 처리하는 확인 절차가 있으나, 먼저 직접 저장하는 편이 안전합니다.
- 실패하면 해제가 완료된 것으로 생각하지 말고 네트워크와 오류 메시지를 확인하세요.

다른 PC에서 이미 열려 있는 앱의 상태가 원격 해제와 동시에 즉시 바뀐다고 보장하지는 않습니다. 서버 재검증 상태와 안내를 확인해야 합니다.

## 오프라인 사용과 재검증

인증된 라이선스는 서버 정책에 따른 재검증 주기와 오프라인 유예 기간을 사용합니다.

- 유효한 이전 인증과 남은 유예 기간이 있으면 일시적인 통신 실패에도 Pro를 유지할 수 있습니다.
- 유예 기간이 만료되면 다시 온라인으로 검증하기 전까지 Lite로 돌아갈 수 있습니다.
- 네트워크 오류와 키 폐기·정지 같은 서버의 명시적 거부는 다릅니다. 폐기된 키를 단순한 오프라인 유예로 계속 사용할 수 있다고 가정하지 마세요.
- 주기와 유예 기간은 키 정책에 따라 달라지므로 모든 사용자에게 고정된 일수라고 안내하지 않습니다.

“이전 상태 유지”라는 안내는 무기한 오프라인 사용을 뜻하지 않습니다. 장기간 오프라인 작업 전에는 인증 상태와 저장 파일을 확인하세요.

## 키가 교체되었을 때

운영자로부터 새 키를 받았다면 기존 키 대신 새 키를 사용합니다. 교체는 기존 키를 폐기하는 절차이므로 이전 키의 재사용은 불가능할 수 있습니다. 접속에 실패하면 새 키를 정확하게 입력했는지와 연결된 기기 수를 확인하세요.

## 자주 확인할 문제

| 현상 | 확인할 내용 |
| --- | --- |
| 인증 실패 | 키 오타, 네트워크, 키 상태, 기기 한도 |
| Pro였는데 Lite로 표시 | 유예 만료, 서버 재검증 결과, 키 정지·폐기 여부 |
| 필터가 비활성화 | 라이선스 외에도 래스터 여부, 다중 선택, 잠금·숨김, 마스크 편집 상태 |
| 기기 해제 실패 | 인터넷 연결과 최신 기기 목록. 성공 확인 전에 다른 PC로 이동하지 않기 |
| 기존 문서와 제한이 다름 | 설치한 버전과 이 위키가 설명하는 현재 소스 기준을 비교 |

라이선스 키는 공개 게시글이나 스크린샷에 노출하지 마세요. 사용자 라이선스 관리 창과 개발자용 관리자 도구는 서로 다른 기능입니다.
