# 선택 메뉴

선택 메뉴는 2D 텍스처 픽셀과 3D 모델 면 중 작업 대상을 정합니다. 선택 범위가 있으면 브러시, 채우기, 필터, 마스크 편집이 그 범위에 제한됩니다.

## 2D 선택

- `자유형 올가미`: 자유롭게 그린 영역을 선택합니다.
- `사각`: 직사각형 영역을 선택합니다.
- `꺾은 선`: 여러 점으로 다각형 영역을 지정합니다.
- `자유 변형` (`Ctrl+T`): 선택한 픽셀을 이동하고 변형합니다. `Enter`로 확정하고 `Esc`로 취소합니다.

## 3D 선택

- `면`: 모델 표면의 면을 직접 선택합니다.
- `올가미`: 화면에 그린 자유형 범위와 겹치는 면을 선택합니다.
- `사각형`: 화면의 사각형 범위와 겹치는 면을 선택합니다.
- `Mesh`: 메시 단위 선택을 사용합니다.

## 공통 명령

| 기능 | 설명 | 단축키 |
| --- | --- | --- |
| 전체 선택 | 현재 포인터가 놓인 뷰의 전체 픽셀 또는 면을 선택합니다. | `Ctrl+A` |
| 선택 반전 | 선택된 부분과 선택되지 않은 부분을 뒤집습니다. | `Ctrl+I` |
| 선택 해제 | 현재 선택을 제거합니다. | `Ctrl+D` |
| 마스크 복사/붙여넣기 | 활성 레이어의 마스크를 복사하고 다른 레이어에 적용합니다. | - |
| 마스크 깜박임 | 활성 레이어 마스크를 잠시 확인합니다. | `Q` |

자세한 차이점과 작업 예시는 [선택과 변형](편집/선택과 변형.md)을 참고하세요.
