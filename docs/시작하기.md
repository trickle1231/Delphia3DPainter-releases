# 시작하기

Delphia3DPainter는 모델의 UV와 텍스처 캔버스를 함께 보면서 2D 또는 3D 화면에 페인팅하는 도구입니다.

## 기본 작업 순서

1. [프로젝트 시작](시작하기/프로젝트 시작.md)에서 모델을 불러옵니다.
2. **파일 > 캔버스 설정...**에서 재질과 텍스처 슬롯을 확인합니다.
3. 래스터 레이어를 추가하고 브러시, 채우기, 지우개로 작업합니다.
4. 필요하면 [선택과 변형](편집/선택과 변형.md), [레이어와 마스크](편집/레이어와 마스크.md), 필터를 사용합니다.
5. `.dpp` 프로젝트를 저장한 뒤 이미지 또는 모델을 내보냅니다.

## 메뉴를 읽는 방법

상단 탭은 앱의 메뉴 구조에 맞춰 정리되어 있습니다. 각 탭의 첫 페이지는 해당 메뉴에 포함된 기능을 한눈에 설명하고, 아래 항목은 작업별 상세 문서입니다.

2D와 3D에서 같은 명령을 실행해도 선택 대상이 달라질 수 있습니다. 선택, 채우기, 필터를 실행하기 전에는 마우스 포인터가 원하는 뷰 위에 있는지 확인하세요.
