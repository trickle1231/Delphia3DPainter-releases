# AO 베이크 작업

**베이크 > AO Bake...** 또는 `Ctrl+Alt+B`로 GPU Bake V2 작업창을 엽니다. 현재 UI는 **AO 전용**이며 전체 화면의 모달 작업창입니다.

AO는 모델 주변의 가림을 바탕으로 명암 정보를 만드는 보조 텍스처입니다. 기존 페인트를 자동으로 마감하거나 모든 재질을 물리적으로 정확하게 표현하는 기능은 아닙니다.

## 필요한 데이터와 실행 환경

- 앱에 불러온 모델의 정점·삼각형·UV·재질 정보를 사용합니다.
- 유효한 UV와 베이크할 재질이 필요합니다.
- GPU 백엔드는 OpenGL 4.3 컨텍스트와 컴퓨트 셰이더를 사용합니다. 실제 동작 가능 여부는 GPU와 드라이버에 따라 달라집니다.
- 현재 경로는 GPU 베이크입니다. GPU 초기화나 계산에 실패하면 자동으로 예전 CPU 베이크 결과를 대신 제공한다고 가정하지 마세요.

UV가 겹치거나 삼각형이 잘못됐거나 표면 방향이 뒤집혔다면 결과가 예상과 다를 수 있습니다. 먼저 모델과 UV를 점검하세요.

## 작업창 구성

| 항목 | 의미 |
| --- | --- |
| Bake Size | 512×512, 1024×1024, 2048×2048, 4096×4096. 기본값은 1024입니다. |
| Bake Materials | 생성할 재질 목록입니다. 체크 여부가 계산 대상을 결정합니다. |
| Select All / Select None | 모든 재질의 체크를 켜거나 끕니다. |
| Bake AO | 체크한 재질을 대상으로 계산을 시작합니다. |
| Cancel Bake | 취소를 요청하는 버튼입니다. 현재 처리 구조의 반응 제한은 아래를 참고하세요. |
| 미리보기 | 계산된 재질의 AO를 확인합니다. 재질 행을 선택해 결과를 바꿉니다. |
| Export Current AO PNG | 현재 표시된 AO 결과 한 개를 PNG로 저장합니다. |
| Exit | 작업창을 닫습니다. 계산 중에는 비활성화됩니다. |

재질의 **체크**와 **행 선택**은 다릅니다. 체크는 베이크할 대상, 행 선택은 결과를 볼 대상입니다.

현재 작업창에는 Curvature, Cavity, 하이폴리 소스, 케이지, AO 반경·강도·샘플 수 조절 UI가 없습니다. 출력 형식도 이 창에서는 PNG입니다. 예전 패널의 TGA·BMP 내보내기 설명을 적용하지 마세요.

## 기본 작업 순서

1. 모델과 재질을 준비하고 프로젝트를 저장합니다.
2. **AO Bake...**를 엽니다.
3. Bake Size를 정합니다. 처음에는 512 또는 1024로 형상과 UV 결과부터 확인합니다.
4. Bake Materials에서 최소 한 개의 재질을 체크합니다.
5. **Bake AO**를 누르고 완료 또는 오류 안내를 기다립니다.
6. 완료 후 결과가 생성된 재질 행을 선택해 확인합니다.
7. 필요한 결과마다 **Export Current AO PNG**로 따로 저장합니다.
8. **Exit**로 닫고 필요한 캔버스에 결과를 레이어로 추가합니다.

재질을 하나도 체크하지 않으면 결과가 생성되지 않습니다. 재질 행을 클릭했더라도 그 재질을 체크하지 않고 베이크했다면 새 결과가 없을 수 있으므로, 화면의 미리보기와 상태의 재질 이름도 함께 확인하세요.

## 레이어로 추가하기

1. 결과를 넣을 재질과 텍스처 캔버스를 선택합니다.
2. 레이어 패널의 **레이어 추가 메뉴**를 엽니다.
3. **베이크 레이어 추가 > AO (GPU Bake V2)**를 선택합니다.
4. 새 **AO Bake** 래스터 레이어를 확인합니다.
5. 원하는 합성 방식에 맞춰 불투명도·혼합 모드·위치를 조절합니다.

추가된 레이어의 기본값은 **일반 합성, 불투명도 100%**입니다. 자동으로 Multiply가 설정되는 것은 아닙니다.

베이크 해상도와 캔버스 해상도가 다르면 **캔버스 크기에 맞춰 리사이즈**하여 넣습니다. 4096 AO를 2048 캔버스에 넣는다고 캔버스가 4096으로 바뀌지는 않습니다. 원본 해상도가 필요하면 PNG도 따로 저장하세요.

여러 재질이 하나의 캔버스에 연결되어 있으면 현재 추가 경로는 연결된 재질 이름을 정렬한 첫 항목의 결과를 사용합니다. 여러 AO 결과를 자동으로 합쳐 주는 기능이 아니므로 공유 캔버스에서는 재질 대응을 특히 확인하세요.

베이크 결과 캐시는 작업 중 레이어로 가져오기 위한 데이터입니다. 다음 베이크나 프로젝트 전환 이후에도 계속 남는 영구 보관본으로 의존하지 말고, 필요한 결과는 레이어로 추가해 프로젝트를 저장하거나 PNG로 내보내세요.

## 성능과 취소에 관한 현재 제한

GPU를 사용하지만, 현재 연결된 실행 경로는 OpenGL 자원의 생성·사용·정리를 **UI 스레드**에서 수행합니다. 별도의 비동기 렌더 워커가 완성된 구조가 아닙니다.

- 계산 중 다른 작업을 계속할 수 있다고 보장하지 않습니다.
- 진행 표시가 재질 단위로 바뀌거나 긴 계산 동안 멈춘 것처럼 보일 수 있습니다.
- 취소 버튼이 있어도 긴 GPU 작업 중 즉시 입력을 처리하지 못할 수 있습니다.
- 종료 버튼도 계산 중 비활성화됩니다.
- 먼저 작은 해상도와 적은 재질로 시험하고, 중요한 프로젝트는 실행 전에 저장하세요.

이것은 색상 필터·노이즈·경사 블러 대화상자의 백그라운드 미리보기와 다른 동작입니다.

## Lite와 해상도

현재 AO Bake V2는 Lite에서도 열리며 Bake Size에는 4096까지 표시됩니다. Lite 편집 캔버스 최대 크기 2048px와는 별도입니다. 결과를 캔버스에 추가할 때는 대상 캔버스의 크기를 따릅니다.

## 문제 해결

| 현상 | 확인할 내용 |
| --- | --- |
| 재질 목록이 비어 있음 | 모델이 로드됐는지, 재질 바인딩이 있는지 확인합니다. |
| 결과가 생성되지 않음 | 최소 한 개를 체크했는지, 완료 상태인지, 오류 메시지가 있는지 확인합니다. |
| GPU 초기화·셰이더·읽기 오류 | GPU 모델과 드라이버, 해상도, 모델 정보를 함께 기록합니다. CPU 자동 대체를 기대하지 마세요. |
| AO 레이어 추가 시 결과 없음 | 현재 캔버스에 연결된 재질의 결과를 이번 베이크에서 생성했는지 확인합니다. |
| 다른 재질의 이미지가 보이는 것 같음 | 체크 대상·선택한 행·실제 미리보기의 재질 이름을 비교합니다. |
| 결과를 넣었더니 해상도가 달라짐 | 새 레이어는 현재 캔버스 크기에 맞춰집니다. 원본 PNG와 비교하세요. |
| 클릭·취소 반응이 늦음 | 현재 UI 스레드 실행 제한입니다. 다음 시험은 낮은 해상도로 진행하세요. |

오류 제보에는 앱 버전, GPU·드라이버, 해상도, 재질 수, 오류 문구를 포함하면 재현에 도움이 됩니다.
