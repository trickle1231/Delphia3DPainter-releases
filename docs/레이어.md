# 레이어 메뉴

레이어 메뉴는 텍스처를 구성하는 레이어를 만들고 정리하는 기능을 제공합니다.

## 레이어 추가

| 기능 | 용도 |
| --- | --- |
| 래스터 레이어 추가 | 브러시, 지우개, 채우기, 필터로 직접 편집하는 레이어를 만듭니다. |
| 채우기 레이어 추가 | 색 또는 채우기 기반 내용을 별도 레이어로 관리합니다. |
| 소스 텍스처 추가 | 등록된 소스 텍스처를 레이어로 가져옵니다. |
| 이미지 불러와 레이어 추가 | 외부 이미지를 현재 캔버스에 새 레이어로 추가합니다. |

## 정리와 합성

- **레이어 복사**, **레이어 잘라내기**, **레이어 붙여넣기**로 레이어를 다른 위치나 프로젝트에 옮깁니다.
- **선택 레이어를 그룹으로 묶기** (`Ctrl+G`)는 여러 레이어를 하나의 그룹으로 관리합니다.
- **아래 레이어 병합** (`Ctrl+E`)은 현재 레이어를 바로 아래 레이어에 합칩니다. 병합 전 원본을 보존하려면 먼저 복사하거나 프로젝트를 저장하세요.

레이어의 표시, 불투명도, 혼합 모드, 잠금과 마스크 사용법은 [레이어와 마스크](편집/레이어와 마스크.md)에 정리되어 있습니다.
