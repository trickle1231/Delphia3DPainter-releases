    브러시 및 지우개

    브러시는 2D UV 뷰의 픽셀과 3D 모델의 표면에 색을 칠하는 도구입니다. B는 브러시, E는 지우개를 선택합니다. 두 도구는 같은 팁·다이내믹·살포 설정을 사용하지만, 지우개는 활성 래스터 레이어의 픽셀을 투명하게 만듭니다.

    브러시가 적용되지 않으면 활성 레이어가 래스터 레이어인지, 잠겨 있지 않은지, 선택 영역이 작업하려는 위치를 포함하는지 확인하세요.

    브러시 목록 패널

    브러시 목록은 브러시와 지우개 탭으로 나뉩니다. 프리셋을 선택하면 해당 설정이 즉시 적용되고, 해당 탭을 고르면 브러시 또는 지우개 도구로 전환됩니다.

    • 목록을 드래그하여 프리셋 순서를 바꿀 수 있습니다.
    • 프리셋을 두 번 클릭하면 이름을 바꿀 수 있습니다.
    • 프리셋을 오른쪽 클릭하면 빠른 설정 메뉴를 열 수 있습니다.
    • 패널 메뉴에서는 프리셋 추가, 복제, 이름 변경, 삭제, JSON 가져오기·내보내기, 기본 프리셋 복원을 할 수 있습니다.
    • 브러시 테스트는 실제 캔버스를 수정하지 않고 획을 시험할 때 사용합니다.

    프리셋은 크기, 팁, 필압, 살포 등 아래 설정 값을 함께 저장합니다. 자주 쓰는 획을 만든 뒤 복제하여 변형하면 기본 프리셋을 잃지 않고 관리할 수 있습니다.

    브러시 설정 패널

    설정 패널은 기본, 브러시 팁, 다이내믹, 살포 탭으로 구성됩니다. 각 탭 위쪽의 브러시 미리보기는 현재 설정으로 만들어질 획을 빠르게 확인하는 용도입니다.

    기본

    속성 기능
    크기 팁의 지름을 1–200 px 범위에서 정합니다.
    하드니스 가장자리의 선명도를 정합니다. 값이 높을수록 경계가 또렷하고, 낮을수록 부드럽게 흐려집니다.
    간격 드래그 중 찍히는 팁 도장의 간격을 정합니다. 낮으면 연속적인 선, 높으면 점점이 끊긴 선이 됩니다.

    브러시 팁

    속성 기능
    형태 원형 또는 텍스처 팁을 고릅니다. 원형은 기본 도장이고, 텍스처는 이미지의 알파·명암을 이용해 질감 있는 도장을 만듭니다.
    팁 텍스처 파일 소스 브라우저에서 브러시 팁 이미지를 선택합니다. 불러온 이미지는 앱 관리 폴더에 복사되어 원본 파일의 위치가 바뀌어도 프리셋에서 사용할 수 있습니다.
    각도 타원형 또는 텍스처 팁의 방향을 0–360°로 돌립니다.
    둥글기 팁의 원형 비율을 정합니다. 100%는 원형이며, 값을 낮출수록 한 축으로 눌린 타원형이 됩니다.
    Brush Tip Anti-Aliasing 팁 가장자리에 안티앨리어싱을 적용합니다. 끄면 픽셀 아트처럼 경계가 선명한 도장을 만들 수 있습니다.

    다이내믹

    필압을 지원하는 펜 태블릿을 사용하면 압력에 따라 크기와 불투명도를 바꿀 수 있습니다.

    속성 기능
    필압으로 크기 제어 누르는 힘에 따라 브러시 크기를 바꿉니다.
    최소 사이즈 약한 필압에서도 유지할 최소 크기를 0–100%로 정합니다. 0%면 약한 압력에서 매우 작아질 수 있고, 값이 높으면 크기 변화 폭이 줄어듭니다.
    크기 필압 커브 크기 변화 곡선을 조절합니다. 시작·끝점은 고정이며 두 개의 제어점으로 압력 반응을 앞쪽 또는 뒤쪽에 집중시킬 수 있습니다.
    필압으로 불투명도 제어 누르는 힘에 따라 획의 불투명도를 바꿉니다.
    최소 불투명도 약한 필압에서도 유지할 최소 불투명도를 0–100%로 정합니다.
    불투명도 필압 커브 불투명도 변화 곡선을 조절합니다. 크기 커브와 독립적으로 설정합니다.

    살포

    살포는 하나의 도장 대신 여러 입자를 흩뿌리는 효과입니다. 점묘, 먼지, 초크 같은 질감에 적합합니다.

    속성 기능
    살포 효과 살포 모드를 켜거나 끕니다.
    살포 밀도 한 번의 도장에 생성되는 입자 수를 1–64 범위에서 정합니다. 값이 높을수록 더 촘촘해집니다.
    입자 크기 개별 입자의 기본 크기를 1–128 px로 정합니다.
    입자 크기 랜덤 비율 입자마다 크기를 무작위로 바꾸는 정도를 0–100%로 정합니다.
    입자 회전 모든 입자의 기본 회전각을 0–360°로 정합니다. 텍스처 팁에서 특히 차이가 잘 보입니다.
    입자 회전 랜덤 비율 기본 회전각을 중심으로 입자별 회전을 무작위로 흔드는 범위를 0–180°로 정합니다.

    살포 범위와 입자 중앙 밀도는 프리셋에 저장되는 내부 값이지만, 현재 패널에서는 표시되지 않습니다. 살포 범위는 브러시 크기를 기준으로 처리되고, 사용자에게는 살포 밀도만 노출됩니다.

    빠른 사용 예

    • 매끈한 베이스 페인트: 원형 팁, 높은 하드니스, 낮은 간격
    • 부드러운 음영: 원형 팁, 낮은 하드니스, 필압 불투명도 사용
    • 픽셀 작업: 크기 1px, 안티앨리어싱 끔, 간격 낮춤
    • 초크·먼지 질감: 텍스처 팁 또는 살포 효과, 입자 크기 랜덤과 회전 랜덤을 함께 사용
